단품·조각별 칼선 공통
벡터는 일러가 실루엣을 직접 오프셋합니다 — 굽기·임계·곡선 복원을 거치지 않아 선이 물결치지 않습니다 (실측: 래스터 칼선은 실루엣 안팎을 100mm당 7~11회 · ±0.5mm로 넘나듭니다). 사진·임베드 이미지·중첩 클리핑이 있으면 자동으로 래스터로 내려가고 사유를 알립니다.
단품 칼선 — 이 문서의 그림에 재단선
mm 그림 바깥으로 벌릴 거리
mm 칼선 바깥까지 더 인쇄
재단 오차를 흡수하려고 칼선보다 더 크게 인쇄하는 영역입니다 — 실물 실측 3mm. 0 이면 만들지 않습니다.
자동 = 아트가 클립 그룹이면 클립을 넓혀 원본을 더 드러내고(왜곡·빈 곳 없음), 아니면 가장자리 색으로 채웁니다.
가장자리 색 = 링을 원본에서 읽은 가장 큰 면의 색으로 채웁니다(조각마다 제 색). 색을 지어내지 않습니다.
사본 확대 = 옛 방식. 사진에는 그림이 이어지지만 뾰족한 형상은 링의 20%까지 빕니다.
사각 = 선택 영역 기준. 실루엣 = 그림 외곽을 따라감. 오프셋을 주면 모서리는 자동으로 둥글어집니다(반지름 = 오프셋).
실루엣일 때만 적용
사진·이미지는 배경이 흰색이라 그대로 두면 사각형이 됩니다. 자동은 흰 배경이 넓으면 알아서 제거합니다 — 단 흰색 그림도 함께 지워집니다.

이미 칼선인 파일 처리
시트컷 .ai 는 대개 컷 라인만 담고 면이 없습니다. 그대로 두면 마스크가 획(선)만 잡혀 실루엣이 아니라 가느다란 고리가 되고, 모아찍기에서 글자 속에 다른 조각이 들어갑니다. 자동은 선택에 면이 하나도 없으면 닫힌 패스를 면으로 봅니다 — 원본은 건드리지 않고 구울 때만 채웁니다.
곡선은 단품·조각별 칼선 모두에 적용됩니다. 글자·로고의 진짜 코너는 그대로 남습니다(55° 이상 꺾임은 코너로 봅니다).
모아찍기 — 여러 조각을 시트에 배치하고 주문 등록까지
mm 디자인 → 칼선
mm 칼선 ↔ 칼선
재단선 = 디자인 + 여백, 조각 사이는 칼선끼리 간격만큼 벌립니다. 디자인끼리는 여백×2 + 간격만큼 떨어집니다.
도련이 이미 들어간 아트는 여백을 음수로 주세요 — 칼선이 잉크 안쪽에 놓입니다(예: 도련 2mm → 여백 −2).
돔보·시트 재단선은 항상 포함
선택한 조각들을 실제 외곽(이형)으로 맞물려 배치합니다. 결과는 새 문서로 만들어지고 원본은 그대로입니다. 간격은 가장 가까운 지점 기준이며 실제 보장값을 결과에 표시합니다.
네스팅 시트를 주문서 대기함으로 보냅니다(시트 1장 = 1건). 저장 후 에이전트가 자동으로 올리며, 주문서에서 불러 쓰면 됩니다.
