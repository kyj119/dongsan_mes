# 재단 E2E 픽스처

## `opacity-mask.ai` (124×80mm)

- **뒤판** = 마젠타 사각 (CMYK 0/100/0/0)
- **앞** = 불투명도 마스크가 걸린 그라디언트 (실물 `약국.ai` 배경에서 뽑았다)

마스크가 변형(확대·회전)을 따라오지 않으면 **마젠타가 드러난다.** 그래서 판정이 색 하나로 끝난다.

| 상태 | 마젠타 아닌 영역의 폭 |
|---|---|
| 정상 | 판 전체 폭 (≈100%) |
| 마스크 소실 | 배율의 역수만큼 (300% 확대면 ≈33%) |

`npm run cut:e2e` 가 이 파일로 판을 짜고 색으로 판정한다. 실측 재현은
`docs/` 가 아니라 여기 두는 이유 = **게이트가 읽는 자료라 코드 옆에 있어야** 한다.

⚠️ 이 파일을 편집하지 말 것. 편집하면 게이트의 기준이 조용히 바뀐다.

## `nested-group.ai` (60.8x61.23mm)

실물 `동산_260825 상상인테리어,내동초.ai` 의 조각 하나를 그대로 뽑았다.

- **모양** = 45도 돌아간 곱선 도형(4점 전부 curved) + 작은 조각 2개. **사각형이 아니고 테두리도 없다.**
- **구조** = `그룹 > [작은패스, 작은패스, 그룹 > 그룹 > 패스]` — **중첩 그룹**이 핵심이다.
  이 구조여야 PDF 굳히기 임베드가 **사각 클립을 2겹** 만들고, 그때 `mesCut_vecCropClip` 이
  최상위만 풀어 남은 사각이 실루에을 덮는다(2026-09-04 결함).

| 상태 | 굳힌 뒤 칼선 |
|---|---|
| 정상 | 4점 **곡선** 실루에 (rects=0) |
| 결함 | 4점 **축정렬 사각** = 바깥 상자 (rects=1) |

`npm run cut:e2e --only=S` 가 이 파일로 판정한다.
⚠️ **합성 도형으로는 재현되지 않는다** — 타원 중첩그룹으로 시험했더니 수정을 되돌려도 통과했다.
⚠️ 이 파일을 편집하지 말 것. 편집하면 게이트의 기준이 조용히 바뀜다.

## `separated-letters.ai` (130.57x48.73mm)

같은 실물 파일의 **글자 조각** 하나(그룹 하나 안에 떨어진 덩어리 8개).

| 볼 것 | 기대 |
|---|---|
| 칼선 수 | **8줄** — 글자는 글자대로. 바깥 사각으로 감싸지 않는다 |
| 부스러기 | **0** — 최소변 0.2mm 미만 조각이 섮이면 안 된다 |

★ 이 파일이 있는 이유 = **부스러기 검출**이다. 수정을 되돌리면 여기서 `slivers=1` 이 나온다
(컬파운드 패스 안쪽 서브패스라 눈으로는 안 보이고 `closed=true` 라 닫힘 검사도 통과한다).

⚠️ 「조각 하나 = 칼선 하나」를 **바깥 사각으로 묶는 것**으로 오해해 2026-09-04 에 한 번 그렇게
구현했다가 취소했다. 진짜 뜻은 **칼선 하나하나가 끊김 없이 닫혀 있을 것**이다.
⚠️ 이 파일을 편집하지 말 것.
