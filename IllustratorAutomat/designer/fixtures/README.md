# 재단 E2E 픽스처

## `opacity-mask.ai` (124×80mm)

- **뒤판** = 마젠타 사각 (CMYK 0/100/0/0)
- **앞** = 불투명도 마스크가 걸린 그라디언트 (실물 `약국.ai` 배경에서 뽑았다)

마스크가 변형(확대·회전)을 따라오지 않으면 **마젠타가 드러난다.** 그래서 판정이 색 하나로 끝난다.

| 상태 | 마젠타 아닌 영역의 폭 |
|---|---|
| 정상 | 판 전체 폭 (≈100%) |
| 마스크 소실 | 배율의 역수만큼 (300% 확대면 ≈33%) |

`npm run cut:e2e` 가 이 파일로 판을 짜고 색으로 판정한다. 실측 재현은
`docs/` 가 아니라 여기 두는 이유 = **게이트가 읽는 자료라 코드 옆에 있어야** 한다.

⚠️ 이 파일을 편집하지 말 것. 편집하면 게이트의 기준이 조용히 바뀐다.
