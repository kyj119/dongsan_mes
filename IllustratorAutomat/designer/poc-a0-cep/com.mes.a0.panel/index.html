단품·조각별 칼선 공통
자동은 매번 가장 정확한 방법을 고르고 무엇으로 만들었는지 결과에 적습니다 — 맞붙임(여백 0·간격 0·직사각)이면 치수 산수, 아니면 일러의 벡터 오프셋, 사진·임베드 이미지·중첩 클리핑이 있으면 래스터로 내려갑니다(사유 표시).
래스터로 고정은 벡터 경로에 문제가 있을 때만 쓰는 우회로입니다 — 칼선이 실루엣 안팎을 100mm당 7~11회 · ±0.5mm로 넘나듭니다(실측).
고급 · 단품 칼선 — 여기 칸은 이 버튼에만 적용됩니다(판짜기와 별개 · 돔보 없음)
mm 그림 바깥으로 벌릴 거리
mm 칼선 바깥까지 더 인쇄
재단 오차를 흡수하려고 칼선보다 더 크게 인쇄하는 영역입니다 — 실물 실측 3mm. 0 이면 만들지 않습니다.
자동 = 아트가 클립 그룹이면 클립을 넓혀 원본을 더 드러내고(왜곡·빈 곳 없음), 아니면 아래 규칙을 씁니다.
여백 > 0 이면 칼선까지의 구간에 아트가 없으므로 한 색(기본 흰색)으로 채웁니다.
여백 0 이면 아트가 칼선까지 차 있는데도 한 색으로 채웁니다 — 색이 이어지지 않으니 여백을 주거나 아트에 도련을 넣으세요.
사본 확대 = 사진처럼 오프셋이 안 먹는 아트용. 뾰족한 형상은 링의 20%까지 빕니다.
⚠️ 도형마다 벌리는 옛 방식은 뺐습니다 — 내부 선이 칼선 밖으로 튀어나옵니다(원리상 한계).
사각 = 선택 영역 기준. 실루엣 = 그림 외곽을 따라감. 오프셋을 주면 모서리는 자동으로 둥글어집니다(반지름 = 오프셋).

도련은 칼선 바깥으로 나가므로 간격 ≥ 도련×2 라야 옆 조각 도련과 안 겹칩니다. 모자라면 간격을 자동으로 올리고 결과에 알립니다 — 겹치면 재단 오차 때 옆 디자인 색이 넘어옵니다.
재단선 = 디자인 + 여백, 조각 사이는 칼선끼리 간격만큼 벌립니다. 디자인끼리는 여백×2 + 간격만큼 떨어집니다.
도련이 이미 들어간 아트는 여백을 음수로 주세요 — 칼선이 잉크 안쪽에 놓입니다(예: 도련 2mm → 여백 −2).
돔보·시트 재단선은 항상 포함
선택한 조각들을 실제 외곽(이형)으로 맞물려 배치합니다. 결과는 새 문서로 만들어지고 원본은 그대로입니다. 간격은 가장 가까운 지점 기준이며 실제 보장값을 결과에 표시합니다.

1/S 로 저장 — 파일명은 실물 규격
파일 배율은 지금 열려 있는 아트의 축척, 저장 배율은 결과를 몇 분의 1로 저장할지입니다. 둘이 다르면 조각을 그만큼 리사이즈해서 판을 짭니다(원본은 건드리지 않습니다).
예) 1:1 원본을 저장 1/2 로 두면 실물 6m 짜리도 한 대지에 담깁니다 — 파일명은 실물 규격이고 RIP 에서 그 크기로 출력하면 됩니다.
⚠️ 저장 배율을 낮추면 돔보·칼선도 같이 작아집니다. 반드시 파일명 규격대로 확대 출력해야 재단기가 돔보를 읽습니다.
