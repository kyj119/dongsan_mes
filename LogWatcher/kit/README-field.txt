MES LogWatcher 현장 키트
========================

사용법: START.bat 더블클릭 → 번호 선택. (판단이 필요한 건 없습니다)

 [1] 신규 장비 진단
     이 PC 의 출력 로그가 어디 있는지 찾습니다.
     "실제 출력 1건 가능?" 에 y = 마커 방식(가장 정확, 원단·잉크 소모),
     n = 자동 탐색만. 끝나면 "수거" 폴더가 생깁니다 → 폴더째 개발자에게 전달.

 [2] LogWatcher 설치/업데이트
     이미 LogWatcher 가 도는 PC: 새 버전으로 교체합니다 (설정은 보존).
     처음 설치하는 PC: 개발자가 config\<PC이름>\ 을 키트에 넣어준 뒤에만 진행됩니다.
     중간에 관리자 권한 창이 뜨면 [예] 를 누르세요.

 [3] EPSON 취소코드 수거 (EPSON Edge Print PC 전용)
     화면 안내대로 작은 잡 1건을 출력 시작 → 곧바로 취소 → Enter.

주의
 - Z: 드라이브가 없는 PC 는 이 폴더를 USB 로 통째 복사해서 실행하고,
   끝나면 USB 를 다시 가져옵니다 ("수거" 폴더가 결과물입니다).
 - 키트 폴더에서 파일을 개별로 빼서 실행하지 마세요. 폴더째 써야 합니다.
