## 판단 기준 / 결정 이유
- 계산서·급여 동산기획 분리 = 사용자 확인. GP 30.7%→16.5% 착시 정정의 핵심.
- 재고평가 = 기초·기말 재고파일 실측 + 유사폭 단가 보간(매입 없는 품목). 단가는 폭 비례(2코팅 40폭288~152폭912원/yd).
