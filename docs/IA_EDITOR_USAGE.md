# /ia-editor 사용법 — 대지 편집 · 시트 네스팅 · 이형 인터록

> 메뉴: **생산 > IA 편집기** (`/ia-editor`). 권한: ADMIN/MANAGER/DESIGNER.
> 고객 시안을 한 화면에서 **그룹 추출 → 대지 배치/편집 → 시트 네스팅 → 주문/출력**까지 잇는 도구.
> 최종 업데이트: 2026-06-19 (이형 true-shape 수동 인터록 추가).

---

## 0. 두 개의 뷰

상단 토글로 전환합니다.

| 뷰 | 용도 |
|----|------|
| **파일 처리** | 고객 시안 업로드 → 그룹 추출(ExtractGroups) → 그룹 썸네일/원본 아카이브 |
| **대지 편집 (네스팅 포함)** | 추출 그룹을 큰 대지에 객체로 놓고 크기·마감·돔보·**시트 네스팅(이형 인터록)** 편집 → 주문 |

---

## 1. 파일 처리 — 시안 준비

1. 드롭존에 고객 **AI/EPS 파일**을 끌어다 놓거나 클릭해 업로드 → 파일별 탭 생성.
2. 에이전트가 **ExtractGroups**로 분석 → 대분류별 **그룹**과 썸네일이 표시됨(분석 완료 = `done`).
3. 원본은 `Z:\원본\…`에 자동 아카이브(가공 후에도 보존).

> 완성본/가공본을 분석 없이 라인에 직접 붙이는 **직접 연결**(주문서 품목행의 '파일 연결')은 별도 경로입니다. 본 문서는 대지 편집/네스팅 중심.

---

## 2. 대지 편집 — 기본 조작

`대지 편집` 뷰는 **좌(팔레트) · 중앙(대지 캔버스) · 우(인스펙터/네스팅 패널)** 3단입니다.

### 객체 올리기
- **팔레트**에서 그룹 썸네일을 클릭 → 대지에 객체로 추가(실제 크기, 0.3px/mm).
- 툴바 **`모두 배치`** → 모든 그룹을 격자로 한 번에 배치.

### 툴바
`전체보기` · `−/+`(줌) · `비율잠금` · **`모두 배치`** · **`시트 네스팅`** · `대지 비우기` · **`주문으로 보내기`**

### 핫키 (대지 뷰, 입력칸 포커스가 아닐 때)
| 키 | 동작 |
|----|------|
| 드래그 | 객체 이동 |
| **R** | 선택 객체 **90° 회전** (2번=180°, 3번=270°) |
| **D** | 복제 |
| **Del / Backspace** | 제거 |
| **← ↑ ↓ →** | 1mm 이동 (Shift = 10mm) |
| **휠** | 줌 / **Space+드래그** | 팬 |
| **Esc** | 선택 해제 |
| **1~9** | 마감 프리셋 적용 |
| **T** | 돔보(트림마크) 토글 |

### 인스펙터 (객체 선택 시 우측)
- **크기(cm)** — 비율잠금 토글. 목표 크기로 키우면 출력 시 그 크기로 스케일(opt-in).
- **마감 프리셋(1~9)** + **상/하/좌/우** 면별 마감방식 → 여백(cm) 벡터 근사 오버레이(앰버).
- **90°(R)** 회전, **돔보(T)**.
- **파일 배율 1/N** — 소스가 실제의 1/N 축소본일 때(현수막 등). 마진·돔보·배치가 N배 보정됨.
- **출력 크기 · 프리플라이트** — 비율 불일치/확대배율 경고.

> 자동 저장: 대지 배치·설정은 브라우저 localStorage에 저장돼 새로고침해도 복원됩니다.

## 3. 시트 네스팅 — 자동 배치 (시작점)

툴바 **`시트 네스팅`** → 우측 패널.

| 항목 | 설명 |
|------|------|
| **대상 그룹(동일 품목)** | 네스팅할 그룹 1종 |
| **수량** | 조각 수 |
| **모드** | **롤**(폭 고정·길이 가변) / **평판**(고정 W×H·여러 판) |
| **규격** | 롤폭 914·1050·1270·1370·1520mm / 평판 900×1800·1200×2400mm |
| **간격(cm)** | 조각 사이 간격 |
| **돔보 여백(cm)** | 시트 둘레 재단 여백 |
| **조각 W/H(cm)** | 비우면 검출 크기, 입력 시 그 크기로 스케일 |
| **파일 1/N** | 소스 축소 배율 |

**`대지에 배치`** → `shelfBinPack`(바운딩박스 패킹)으로 시트 1개 + 조각들이 **대지 객체로** 생성됩니다. 효율%가 시트 라벨에 표시. 평판은 초과 시 자동 다음 판.

> 이 자동 배치가 **시작점**입니다. 그대로 주문해도 되고, 아래 이형 인터록으로 더 촘촘히 다듬을 수 있습니다.

---

## 4. ★ 이형(true-shape) 수동 인터록 — 핵심

**왜 필요한가**: 자동 패킹은 각 조각을 **사각형(바운딩박스)** 으로 취급하므로, 삼각형·곡선 등 이형 도형 사이에 빈 공간이 낭비됩니다. 실제 잉크는 사각형이 아니므로, 조각들의 **바운딩박스를 겹쳐** 끼워 맞추면 같은 시트에 더 많이 넣어 자재를 아낄 수 있습니다.

**작업 흐름**
1. `시트 네스팅`으로 자동 배치(3장)를 먼저 만든다.
2. 시트 안의 **조각을 드래그**해 서로의 오목한 부분에 끼워 넣는다. **바운딩박스가 겹쳐도 됩니다** (실제 그림이 안 겹치면 OK — 겹침 판단은 작업자 책임).
3. 필요하면 **R로 회전**(0/90/**180**/270 모두 가능 — 180°는 R 2번). 이형 도형은 뒤집어야 맞물리는 경우가 많습니다.
4. **롤 모드**: 조각을 위로 촘촘히 밀면 **시트(롤) 길이가 자동으로 줄어듭니다** → 자재 절감. 시트 라벨의 **효율%**(겹침으로 100% 초과 시 **`인터록 N%`**)로 밀도를 확인.

**시트 멤버십(중요)**
- 조각의 **중심이 시트 사각형 안**에 있으면 그 시트에 포함됩니다. 밖으로 빼면 개별 라인이 되고, 다른 시트 안으로 끌어오면 그 시트에 합쳐집니다(**드래그 인/아웃**).
- 한 시트에는 **동일 품목 + 단일 소스 파일**만 묶입니다. 다른 파일의 조각을 올리면 자동으로 제외돼 개별 라인이 됩니다.

**경고 표시**
- 조각이 시트 경계를 벗어나면 시트 라벨 아래 **`⚠ 조각이 시트 경계를 벗어남(출력 시 잘릴 수 있음)`**.

**핵심 보장**: 주문 시 **현재 대지에 보이는 배치 그대로**(각 조각의 위치·회전) 출력됩니다. 0/90/180/270 회전 모두 정확히 반영됩니다.

## 5. 주문으로 보내기

툴바 **`주문으로 보내기`** → 모달.

- **모드**: `신규 주문 생성`(거래처·납품일 지정) / `기존 주문에 추가`(주문번호/거래처 검색 → **출력완료(PRINT_DONE)까지의 주문**에만 추가).
- **라인 구성**: 시트 = **1라인(수량 = 조각 수)**, 시트에 안 묶인 개별 객체 = 각 1라인.
- 라인별 **품목 지정**(품목 검색 → base_price 자동) · 수량 · 단가(고정/면적단가).
- 제출 → 각 시트의 **현재 조각 배치가 placements로 캡처**되어 주문에 저장됩니다.
  - 신규: `POST /api/orders` (주문·카드·AI_PROCESS 작업 생성)
  - 추가: `POST /api/orders/:id/items` (신규 라인만 추가, 카드번호 연속, 출력완료면 '출력중'으로 되돌림)

---

## 6. 출력 (에이전트)

주문이 생기면 IA 에이전트(`IllustratorAutomat`)가 AI_PROCESS 작업을 받아:
- 시트 라인 → **`SheetLayout.jsx`** 로 시트별 **EPS / DXF / JPG** 생성(주문 폴더 `Z:\DESIGN\…`).
- 조각들이 **인터록 배치 그대로**(위치·회전 0/90/180/270) 배치됩니다.
- 3레이어: **Design**(인쇄) · **CutLine**(재단, 인쇄 OFF) · **Dombo**(돔보 마크).

---

## 7. 주의 / 팁

- **한 시트 = 동일 품목 + 단일 소스 파일.** 혼재 시 소수파 조각은 개별 라인으로 빠집니다.
- **롤**은 길이가 자동 단축(인터록 효과가 바로 보임), **평판**은 고정 W×H라 초과 시 경고.
- 겹침(인터록)은 **작업자가 실제 잉크 겹침을 책임**집니다 — 바운딩박스 겹침만 허용, 그림이 겹치면 안 됩니다.
- 대지 작업은 **자동 저장**(localStorage). 다른 PC/브라우저에는 동기화되지 않습니다.
- 회전은 **90° 스냅**(0/90/180/270)만 출력에 충실합니다(임의 각도 미지원).
