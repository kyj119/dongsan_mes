# Z: 작업파일명 규칙 (2026-09-07 확정)

> **초안(2026-08-12)에서 규칙을 9개 → 4개로 줄였다.**
> 초안을 내보내지 않은 25일 동안 위반율은 저절로 좋아지기는커녕 **올랐다**
> (앞머리 괄호 혼입 16.6%→**28.5%** · 구분자 47.5%→**53.6%**).
> 지켜지지 않는 규칙을 아홉 개 두는 대신, **자동화에 실제로 기여하는 네 개**만 남긴다.
>
> 근거 = 2026-07-01~09-06 실파일 **8,059건** 실측(초안 4,611 + 재실측 3,448).
> 항목마다 **지금 몇 %가 어긋나는지**를 붙였다 — 근거 없는 규칙은 안 지켜진다.

---

## 왜 이 네 개인가

파일명은 이미 주문서를 채울 정보를 거의 다 담고 있다. 자동화가 막히는 지점은
정보 부족이 아니라 **네 축의 결손**이다.

| 축 | 무엇을 결정하나 | 없으면 |
|---|---|---|
| **규격** | 주문 라인을 찾는 **1순위 앵커** | 그 파일이 어느 주문인지 **영영 모른다** |
| **순번** | **주문 그룹 경계** | 같은 날 같은 거래처가 한 덩어리로 뭉친다 (배정률 90.7% → 45.8%) |
| **거래처** | 앵커 2순위 | 후보가 그날 전체로 벌어진다 |
| **수량** | 그룹 합산 검증 | 초안이 맞는지 확인할 방법이 없다 |

나머지(제품유형 표기·구분자 통일·후가공 문법)는 **파서가 이미 흡수하거나, 사람이 주문서에서
고르는 값**이다. 규칙으로 강제해서 얻을 게 없다 — 그래서 뺐다.

---

## 형식

```
{순번}-{거래처}-{건명}({가로}x{세로}-{수량}장){후가공}_{납기}
```

```
27-연안애드마트-농협공판장(506x92-1장)사방접어미싱_13일 오전직배.eps
```

**UV솔벤 · 현수막 · 전사 세 축 모두 같은 형식이다.**

| 자리 | 필수 | 내용 |
|---|---|---|
| 순번 | ✔ | 그날 접수 순서 `27-` |
| 거래처 | ✔ | 마스터 등록명. **순번 바로 뒤** |
| 건명 | | 현장명·행사명. 전사축은 여기에 품목을 쓴다(§5) |
| 규격·수량 | ✔ | `(가로x세로-수량장)` · cm · **완성 실치수** |
| 후가공 | | 미싱·펀칭·재단 — **규격 괄호 뒤**, `+`로 잇는다 |
| 납기 | | `_13일 오전직배` |

## 1. 규격 — 파일명에 반드시 넣는다 ⚠️ 현재 **7.3% 누락** (현수막축 10.8%)

```
❌ 1팀_0079-10.eps            ❌ 1~3중대.eps            ❌ 선우(홍성) 내포문화진흥원-우측만.eps
✅ (500x90-1장)               ✅ (135x90-5장)
```

**이 규칙 하나가 나머지 셋보다 무겁다.** 파일에 규격이 없으면 주문을 찾을 방법이 아예 없다.

- 단위는 **cm**, 숫자만.
- **완성 실치수**를 쓴다. 실측상 작업파일의 **54%가 축소 저장**(×5 43% · ×2 8% · ×10 3%)인데,
  파일 크기로는 실물을 되돌릴 수 없다 — 파일명이 실물을 말해 주는 **유일한 근거**다.
- 규격을 모르는 파일은 **주문서를 못 만든다.** 급해도 이것만은 적는다.

---

## 2. 수량 — `-N장`, **1장이어도 생략하지 않는다** ⚠️ 현재 **16.6% 누락**

```
❌ (600x70)          ❌ (150x80x4장)
✅ (600x70-1장)      ✅ (150x80-4장)
```

- **`조` = 1쌍(2개)**. 낱장이면 `장`.
- `벌` 은 의미가 확정되지 않았다 → **쓰지 말고** `장` 또는 `조`로.
- **수량은 파일에만 쓴다.** 폴더에 `총2장`·`-100장-`을 적으면 두 군데가 어긋난다.

---

## 3. 접수순번 — `27-` 로 시작한다 ⚠️ 현재 **28.8% 누락** (전사축 **97.8%**)

- 두 자리 이상, **그날 접수 순서**.
- **전사축도 붙인다.** 지금 전사축은 순번이 사실상 없어(2.2%) 같은 날 같은 거래처 건이
  전부 한 덩어리로 뭉친다. 이 한 줄이 그룹 배정률을 **45.8% → 90.7%** 로 올린다.
- 한 주문에 파일이 여러 개면 **같은 순번**을 쓰고 건명으로 구분한다
  (`온누리상품권01`·`온누리상품권02`). 굳이 라인번호를 매길 필요는 없다.

---

## 4. 거래처 — 마스터 등록명을 **순번 바로 뒤에** ⚠️ 현재 **14.8% 판독 불가**

```
❌ 반석동01(…)                        ← 건명만 있어 거래처를 알 수 없다
❌ 레코드치어풀(1000X160-1장)…         ← 같음
❌ 가나실사                            ← 약칭
✅ 17-가나그래픽스-레코드치어풀(1000x160-1장)사방줄미싱_퇴근전
```

- 약칭·별칭 금지. **건명은 거래처를 대신하지 못한다.**
- 폴더로 묶는 경우에도 **파일에 거래처를 남긴다** — 파일만 따로 옮겨지면 폴더는 안 따라온다.

---

## 5. 전사축 — 품목을 알 수 있는 말을 **건명 자리에** 쓴다

전사축은 규격만으로 품목이 안 정해진다. `135x90` 하나에 **태극기7호 · 새마을기7호 ·
민방위기7호 …** 가 걸린다. 실측상 품목을 알 수 있는 파일은 **4.0%** 뿐이다.

```
❌ 대구우승사 군산시(135-90-2장).eps
✅ 18-대구우승사-군산시 태극기7호(135x90-2장).eps

❌ 1.공태현,최찬(60-180-5조).eps
✅ 12-서림광고기획-공태현,최찬 워킹배너H형(60x180-5조).eps
```

`깃발` `만장기` `가로등배너` `윈드배너S형` `워킹배너H형` `어구실명제` `태극기7호` `새마을기7호`
처럼 **품목을 알 수 있는 말**을 남긴다. 원단(`폰지`/`매쉬`/`샤틴`)이 다르면 함께 적는다.
폴더로 묶어 폴더명에 써도 된다(`12-서림광고기획-11일 오전직배\윈드배너S형\`).

## 하지 말 것

### ① 앞머리 괄호 — **제품유형 괄호는 쓰지 않는다**

```
❌ (솔벤시트+재단)두용기획 내동집(117-182)_퇴근.eps
❌ 02-(UV후렉스+조)공감디자인-수상작패널(397x197-1장)칼재단-급 바로.eps
✅ 05-두용기획-내동집(117x182-1장)재단_퇴근.eps
✅ 02-공감디자인-수상작패널(397x197-1장)칼재단+큰펀칭10개_급 바로.eps
```

이 자리가 **후가공·조명여부·원단폭·코팅을 다 받아 주는 잡동사니 칸**이 되면서
`솔벤시트` 하나가 표기 17종으로 갈라졌다(현재 혼입 **28.5%**).
**품목은 주문서에서 고른다** — 파일명이 결정하지 않는다.

후가공은 **규격 괄호 뒤**에 쓴다. 지금도 대부분 그 자리에 쓰고 있다.

### ② 의미 없는 이름

```
❌ 001.eps  ·  무제-4.ai  ·  1팀_0079-10.eps  ·  1~3중대.eps
❌ 새 폴더 · 새폴더 · 무제 · 제목 없음 · new folder
```

### ③ 폴더에 수량 적기

```
❌ 04-다드림광고-총2장-2일 오후3시 사무실\…
❌ 11-오케이애드공사-금호어울림-100장-13일 방문\1팀_0079-10.eps
✅ 04-다드림광고-2일 오후3시 사무실\04-신탄중앙중(90x340-1장)사방접어미싱+사방큰펀칭.eps
```

## 권장 (틀려도 읽히지만, 맞으면 사람이 편하다)

- **구분자는 소문자 `x`** — 현재 `x` 43% · `X` 24% · 대시 25%로 갈려 있다.
  파서는 셋 다 읽으므로 자동화가 깨지지는 않는다. 다만 대시는 수량 구분자와 겹쳐
  `(110-192.5-1장)` 처럼 사람이 읽기 어려워진다.
- **파일이 2개 이상이면 주문 폴더로 묶는다** — `{순번}-{거래처}-{납기}\`.
  현재 **49.3%** 가 폴더 없이 날짜 폴더에 흩어져 있다.
  `\소형` `\중형` 같은 구분 폴더는 **지금 방식이 맞다. 그대로 두면 된다.**
- **오타를 굳히지 않는다** — `패트베너`(24건)→`패트배너` · `포멕스`→`포맥스` · `매쉬베너`→`매쉬배너`.

## 이 규칙의 수명

이 규칙은 **사람이 파일명을 짓는 동안만** 필요하다.

패널이 만드는 이름이 이 형식과 같은 자리를 쓰기 때문이다.
