# Z: 작업파일명 작성 규칙 — 초안 (2026-08-12)

> **상태: 초안.** 용준님이 검토·확정해 현장에 배포할 것.
> 근거는 2026-07-01~08-11 실파일 **4,611건** 실측(`variant_stats.py`).
> 규칙은 지켜져야 의미가 있으므로, **지금 얼마나 어긋나는지**를 항목마다 붙였다.

## 왜 규칙이 필요한가

파일명은 이미 주문서를 채울 정보를 거의 다 담고 있다(거래처 87% · 규격 87% · 수량 80%).
자동화를 막는 건 정보 부족이 아니라 **같은 것을 다르게 쓰는 것**이다.
`솔벤 시트` 하나에 표기가 **17종**, `수성 현수막`에 **18종** 붙어 있다.

---

## 1. 전체 형식

```
{순번}-{상태}({제품유형}){거래처}-{건명}({규격}-{수량}{단위}){후가공}_{납기} {배송}.eps
```

```
27-(수정)(솔벤현수막)연안애드마트-농협공판장(506x92-1장)사방접어미싱_13일 오전직배.eps
```

| 자리 | 필수 | 내용 |
|---|---|---|
| 순번 | ✔ | 그날 접수 순서. `27-` |
| 상태 | | `(수정)` `(재출력)` `(샘플)` `(추가)` 만 사용 |
| 제품유형 | ✔ | **품목만.** 아래 §2 정본 표기 |
| 거래처 | ✔ | 마스터 등록명 |
| 건명 | | 현장명·행사명 |
| 규격·수량 | ✔ | `(가로x세로-수량장)` cm |
| 후가공 | | 미싱·펀칭·재단 등 |
| 납기·배송 | | `_13일 오전직배` |

---

## 2. 제품유형 괄호에는 **품목만** 쓴다 ★ 가장 중요

> 현재 **16.6%**(528건)가 제품유형 괄호에 후가공을 섞어 쓴다.
> 이것 하나 때문에 `솔벤시트`가 17종으로 갈라졌다.

```
❌ (솔벤시트+재단)   (솔벤시트+돔보)   (포맥스3T+자동바니쉬)   (패트-코팅X)
✅ (솔벤시트)…재단   (솔벤시트)…돔보   (포맥스3T)…자동바니쉬   (패트)…코팅X
```

후가공은 **규격 괄호 뒤**에 쓴다. 지금도 대부분 그 자리에 쓰고 있다(`…(506x92-1장)사방접어미싱`).

### 정본 표기 (이 목록에 없는 말은 쓰지 않는다)

| 정본 | 쓰지 말 것 |
|---|---|
| `솔벤현수막` `솔벤시트` `솔벤그레이시트` `솔벤랩핑시트` `솔벤매쉬` `패트배너` | `패트베너`(36) |
| `수성현수막` `패트` `합성지` `켈` `부직포` `어깨띠` | `현수막`만 쓰기, `250폭`·`한폭출력` (§5) |
| `UV시트` `UV그레이시트` `UV조명후렉스` `UV비조명후렉스` `UV엠보시트` `UV투명시트` | `uv…`(소문자 23.5%), `UV그레이후렉스`, `투코팅` |
| `포맥스2T` `포맥스3T` `포맥스5T` `포맥스8T` `포맥스10T` | `포멕스`(4), `백색3T평판`, `백색3T포맥스` |
| `폼보드5T` `자작나무6T` `자작나무9T` `자작나무12T` | `품보드`(2), `자작6T`, `폼보드평판` |
| `아크릴2T` `아크릴3T` `아크릴5T` (색 지정 시 `아크릴3T검정`) | |
| `매쉬배너` | `매쉬베너`(10), `메쉬배너` |

- **「평판」은 쓰지 않는다.** 소재명을 쓴다 — `백색3T평판` 은 실제로 포맥스 3T였다(19건).
- **「그레이후렉스」는 쓰지 않는다.** `UV비조명후렉스` 로 쓴다(80건).
- **「게시대」는 품목이 아니라 마감이다.** `(수성현수막)…게시대마감` (188건)
- 두께는 **소재 뒤에** 붙인다: `포맥스3T` (✅) / `백색3T포맥스`·`3T포맥스` (❌)
- 조명·비조명은 **품목명에 넣는다**: `UV조명후렉스` (✅) / `UV후렉스+조`·`-조`·`+비`·`-비조` (❌)

## 3. 규격은 `가로x세로`, 소문자 `x` 고정

> 현재 `x` 39.6% · `X` 19.6% · `-`(대시) 27.7% · `×` 0.2%.

```
❌ (506X92-1장)   (120-91)   (110-192.5-1장)
✅ (506x92-1장)   (120x91-1장)   (110x192.5-1장)
```

- 단위는 **cm**, 숫자만.
- 대시(`-`)는 **규격 구분자로 쓰지 않는다** — 수량 구분자와 겹쳐 `(110-192.5-1장)`처럼 읽기 어려워진다.
- 배율 작업(축소 제작)이어도 파일명에는 **완성 실치수**를 쓴다.

---

## 4. 수량은 `-N장` 형식, 단위를 반드시 붙인다

> 현재 20.3%가 수량 표기 없음. 단위는 `장` 71.0% · `조` 4.8% · `개` 2.4% · `벌` 1.1%.

```
❌ (600x70)   (150x80x4장)
✅ (600x70-1장)   (150x80-4장)
```

- `조` = **1쌍(2개)**. 낱장이면 `장`을 쓴다.
- `벌` 은 **의미가 확정되지 않았다** → 당분간 쓰지 말고 `장` 또는 `조`로 쓴다.
- 수량이 1이어도 **`-1장`을 생략하지 않는다.**

---

## 5. 원단 폭은 제품유형이 아니다

```
❌ (250폭)   (한폭출력)   (150폭 중앙출력)
✅ (수성현수막)   … 필요하면 후가공 자리에 `250폭 중앙출력`
```

`250폭`·`280폭`·`300폭`·`320폭`·`한폭`·`장폭출력` 은 **출력 방식**이지 품목이 아니다(62건).

---

## 6. 순번 — 전 축 공통으로 붙인다

> 현재 65.7%만 있다. 없는 1,582건 중 **1,355건이 전사축**이다.

- `01-`, `27-` 처럼 **두 자리 이상**, 그날 접수 순서.
- **전사축도 붙인다.** 지금은 순번이 없어 같은 날 같은 거래처 건이 한 덩어리로 뭉친다.
- 한 주문에 파일이 여러 개면 **같은 순번**을 쓰고 파일명 끝에 `-01`, `-02` 를 붙인다.

---

## 7. 거래처는 마스터 등록명으로

> 현재 12.6%가 거래처를 읽을 수 없다.

- 약칭·별칭 금지. `가나실사` ❌ → `가나그래픽스` ✅
- 제품유형 괄호가 없는 형식이면 **순번 바로 뒤가 거래처**여야 한다.
  `29-선전인쇄-한밭전자거리(…)` ✅ / `반석동01(…)` ❌ (건명만 있어 거래처를 알 수 없다)
- 폴더로 묶는 경우 **폴더명에 거래처**를 넣는다: `07-갈마안전-…\`

---

## 8. 전사축 — 품목을 파일명이나 폴더에 남긴다

> 전사축 1,355건 중 **38.9%는 품목을 정할 단서가 아예 없다.**

규격만으로는 안 된다. `90x135` 하나에 태극기 7호·새마을기 7호·민방위기 7호… **16종**이 걸린다.

```
✅ 폴더:  7월\11일 화요일\광고월드-어구실명제\
✅ 파일:  03-광고월드-어구실명제(60x150-5조).eps
```

`깃발` `만장기` `가로등배너` `윈드배너S형` `워킹배너H형` `어구실명제` `태극기7호` `새마을기7호` 처럼
**품목을 알 수 있는 말**을 파일명이나 폴더에 반드시 남긴다. 원단(`폰지`/`매쉬`/`샤틴`)도 다르면 적는다.

---

## 9. 폴더와 파일의 역할 ★ 폴더는 계속 만든다 (오히려 더)

> **오해 방지**: 폴더를 만들지 말라는 규칙이 **아니다.** 폴더는 권장이다.
> 실측 — 주문용 하위 폴더 **0단계 60.8%** · 1단계 34.0% · 2단계 5.0%.
> **60.8%가 폴더 없이 날짜 폴더에 파일을 흩뿌린 상태**이고, 여기가 진짜 문제다.
> 파일이 2개 이상이면 폴더로 묶는 편이 낫다.

```
{날짜}\{배송구분}\{순번}-{거래처}-{납기}\[{품목·구분}\]{순번}-{라인}-({제품유형}){건명}({규격}-{수량}){후가공}.eps
   └ 기존        └ 기존       └ 주문 1건        └ 선택           └ 라인 1개
```

| 층 | 역할 | 담는 것 |
|---|---|---|
| 배송구분 | 기존 유지 | `방문,직배` `택배` `화물` `간판팀` |
| **주문 폴더** | 주문 1건 | **순번**-거래처-납기 |
| **구분 폴더**(선택) | 라인 묶음 | 품목·규격·크기 — 파일이 많을 때 |
| 파일 | 라인 1개 | 라인번호·제품유형·건명·규격·수량·후가공 |

### 구분 폴더는 지금 방식이 맞다 — 전사축이 좋은 예

```
✅ 주니그래픽-윈드배너\소형              (18개)
✅ 육군부사관학교-대대기,중대기\중대기(80-55-총27장)  (28개)
✅ 충성센터\게양용 · \정기 · \약기
✅ 광고월드-어구실명제\제2진성호-봉미싱
```

거래처·내용·품목으로 묶는 이 방식이 **정확히 §8이 요구하는 것**이다 — `60x180` 규격만으론
가로등배너인지 윈드배너인지 모르는데 폴더가 알려준다. 여기에 **순번만 붙이면 된다**:

```
✅ 12-주니그래픽-11일 오전직배\소형\12-01-(윈드배너S형)…(60x180-5조).eps
```

### 만들지 말아야 할 폴더는 하나뿐

```
❌ 새 폴더 · 새폴더 · 무제 · 제목 없음 · new folder
```
자동 생성 이름 그대로인 것 **134건(2.9%)**. 이름이 없으니 아무 정보도 못 준다.
파일도 마찬가지 — `001.eps` `무제-4.ai` 는 안 된다.

```
❌ 09-(UV후렉스-조)수양광고-…-2일 오후직배\새 폴더\코인동전노래방01(420x130-1장)천갈이.eps
✅ 09-수양광고-2일 오후직배\09-01-(UV조명후렉스)코인동전노래방01(420x130-1장)천갈이.eps
```
(폴더 하나로 충분한데 한 겹 더 판 경우다. 묶을 게 있으면 이름을 주고, 없으면 만들지 않는다.)

## 부록 A — 실제 파일 고치기 예시

> 전부 2026-07~08 실파일이다. 굵게 표시한 부분이 바뀐 곳.

### ① 후가공을 제품유형 괄호에서 뺀다 + 구분자 + 수량 + 순번

```
❌ (솔벤그레이시트+재단)두용기획 내동집(117-182)_퇴근.eps
✅ 05-(솔벤그레이시트)두용기획-내동집(117x182-1장)재단_퇴근.eps
```
`+재단` → 규격 뒤로 · `117-182` → `117x182` · `-1장` 추가 · 순번 `05-` 추가 · 거래처와 건명 사이 `-`

### ② 「평판」은 소재명으로

```
❌ (백색2T평판+재단)두용기획 대전김재권(122-232)_14일점심.eps
✅ 12-(포맥스2T)두용기획-대전김재권(122x232-1장)재단_14일 점심.eps
```

### ③ 후렉스는 조명/비조명을 품목명에 넣는다 + 중간 폴더 제거

```
❌ 09-(UV후렉스-조)수양광고-코인동전노래방(배경안늘려요)-2일 오후직배\새 폴더\
      코인동전노래방01(420x130-1장)천갈이.eps
✅ 09-수양광고-2일 오후직배\
      09-01-(UV조명후렉스)코인동전노래방01(420x130-1장)천갈이.eps
```
`-조` → `조명후렉스` · `새 폴더` 제거 · 파일에도 제품유형을 넣는다(폴더에서만 읽으면 라인별로 다를 때 틀린다)
· `(배경안늘려요)` 같은 지시사항은 괄호 대신 파일명 끝 `_` 뒤에 쓴다

### ④ 대문자 `X` → 소문자 `x`, 폴더의 `총2장`은 빼기

```
❌ 04-(솔벤현수막)다드림광고-총2장-2일 오후3시 사무실\
      신탄중앙중(90X340-1장)사방접어미싱+사방큰펀칭.eps
✅ 04-다드림광고-2일 오후3시 사무실\
      04-01-(솔벤현수막)신탄중앙중(90x340-1장)사방접어미싱+사방큰펀칭.eps
```
폴더의 `총2장`은 수량을 두 군데 적게 만든다 — **수량은 파일에만** 쓴다.

### ⑤ 거래처가 없는 파일 (581건)

```
❌ …\07월\01일\방문,직배\레코드치어풀(1000X160-1장)사방줄미싱.eps
✅ …\07월\01일\방문,직배\17-(솔벤현수막)○○광고-레코드치어풀(1000x160-1장)사방줄미싱_퇴근전.eps
```
건명(`레코드치어풀`)만 있고 거래처가 없다. **건명은 거래처를 대신하지 못한다.**

### ⑥ 파일명이 번호뿐 (`001.eps`·`무제-4.ai`)

```
❌ …\07월\07일\방문, 직배\001.eps   (같은 폴더에 15개)
✅ …\07월\07일\방문,직배\21-(솔벤현수막)○○광고-○○현장(가로x세로-1장)후가공_납기.eps
```

### ⑦ 오타 3종이 한 파일에

```
❌ (매쉬베너+사방큰펀치)두용기횝 내동집유천점(120-180)_3일1시까지.eps
✅ 08-(매쉬배너)두용기획-내동집유천점(120x180-1장)사방큰펀칭_3일 13시.eps
```
`매쉬베너`→`매쉬배너` · `두용기횝`→`두용기획` · `사방큰펀치`→`사방큰펀칭`

### ⑧ 원단 폭은 후가공 자리로

```
❌ 04-(솔벤현수막)시티페인팅-지관말아포장-8일 오전직배\
```

### ⑨ 전사축 — 순번과 품목을 남긴다 (가장 큰 변화)

```
❌ 메인1\7월\10일 금요일\서림광고기획\
      1.공태현,최찬(60-180-5조).eps
✅ 메인1\7월\10일 금요일\12-서림광고기획-11일 오전직배\
      12-01-(워킹배너H형)공태현,최찬(60x180-5조).eps
```
- **순번 `12-`** — 전사축엔 지금 순번이 아예 없어(1,355건 전량) 같은 날 같은 거래처가 한 덩어리로 뭉친다
- **품목 `(워킹배너H형)`** — `60x180` 만으로는 가로등배너인지 워킹배너인지 깃발인지 모른다
- 파일 앞 `1.` `2.` 는 라인번호 자리로 옮긴다(`12-01-`)
- 원단이 다르면 함께 적는다: `(깃발폰지)` `(깃발매쉬)` `(만장기샤틴)`

### ⑨-2 구분 폴더는 그대로 둔다 — 순번만 추가

```
△ 메인1\7월\16일 목요일\주니그래픽-윈드배너\소형\…(18개)
✅ 메인1\7월\16일 목요일\09-주니그래픽-17일 오후직배\소형\
      09-01-(윈드배너S형)○○(60x180-2조).eps
```
`\소형` `\중형` `\대형` 묶음은 **유지한다.** 파일이 18개면 묶는 게 맞다.
`육군부사관학교-대대기,중대기\중대기(80-55-총27장)` 도 마찬가지 —
다만 수량(`총27장`)은 폴더가 아니라 **파일에** 쓴다(§4).

### ⑩ 폴더가 이미 잘 되어 있는 사례 (이대로 두면 된다)

```
✅ 20-(포맥스5T+자동바니쉬)명성-태양당약국-3일 오전직배(간판팀 합배송)\
      태양당약국01(92x237-3장).eps
```
순번·거래처·납기·배송이 폴더에 다 있다. 여기서 고칠 건 **두 가지뿐**:
```
✅ 20-명성-태양당약국-3일 오전직배(간판팀 합배송)\
      20-01-(포맥스5T)태양당약국01(92x237-3장)자동바니쉬.eps
```
제품유형을 **파일로 옮기고**(라인마다 다를 수 있다), `+자동바니쉬`를 후가공 자리로.
