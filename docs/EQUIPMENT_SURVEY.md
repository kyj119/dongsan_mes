# 장비 전수조사 시트 — 동산기획(entity 1)

**작성** 2026-08-05 · **대상** `equipment` 24대 · **입력 화면** `/equipment` → 장비 카드 → 수정

## 왜 자산 대장이 아니라 여기인가

세무장부 고정자산 대장은 **전표 단위**다(`컴퓨터 및 주변기기 외`·`TELEIOS HEXA 외 5건`).
기계를 가리켜 "저게 어느 자산이냐"를 답할 수 없는 자료이고, 앞으로도 그럴 것이다.
**실물 관리의 정본은 `equipment`** 이고 공장 배치도·가동 현황·LogWatcher 가 전부 여기에 붙어 있다.

## 절반은 이미 채워져 있다 — `print_events` 실가동 기록

조사 나가기 전에 **드라이버명·실사용 폭·가동량이 이미 실측되어 있다**(2026-06-01~08-05).
빈칸은 **제조사·모델 실명 / 도입시기** 뿐이다.

## 조사할 것 — 4가지뿐

1. **제조사·모델 실명** (명판 촬영이 가장 빠름)
2. **도입시기** (대략 연도만이라도 — 자산 대장 취득일과 맞춰보면 연결이 확정된다)
3. **HSM-05·HSM-07 실물 유무** · **EPSON 2대 실사용 여부**
4. **전사 4대가 같은 기종인지**

## 입력 방법

`/equipment` → 해당 장비 카드 → **수정**. 저장되는 필드는
`name`(실명) · `printer_name`(모델) · `ip_address` · `zone_id` · `size_type` · `head_count` · `notes`.
**도입시기·제조사는 전용 필드가 없으므로 `notes` 에 적는다**(예: `2023년 도입 · 케이엠테크`).

## 조사 후 이어질 일

- 자산 ↔ 장비 연결(`fixed_assets.equipment_id`) — 큰 장비 8~9대만 되면 충분하다
- 부문 귀속률 상승 — 현재 직접귀속 39%. 다만 **상한은 45% 부근**이다(차량·건물·공장 전체설비·사무기기는 원래 공통)
- 유령 장비 정리 → 공장 배치도·가동률 통계가 정확해진다

## 재현 쿼리

```sql
SELECT e.id, e.name, e.zone_id, p.n AS 가동, p.wmax AS 최대폭, p.drv AS 드라이버
FROM equipment e
LEFT JOIN (
  SELECT equipment_id, COUNT(*) n, MAX(CAST(output_width AS REAL)) wmax, MAX(printer_name) drv
  FROM print_events WHERE print_started_at >= '2026-06-01' GROUP BY equipment_id
) p ON p.equipment_id = e.id
WHERE e.entity_id = 1 ORDER BY COALESCE(p.n,0) DESC;
```
