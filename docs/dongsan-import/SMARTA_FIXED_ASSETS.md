## 재현 방법 (다음에 다시 뽑을 때)

1. WEHAGO 로그인 → 회계관리 → SmartA
2. 전체메뉴 → **고정자산** → **고정자산관리대장**
3. 조건 전부 기본값(0.전체) → **조회**
4. 응답은 `fetch` 훅으로 통째로 받는다(화면 그리드는 가상스크롤이라 DOM 긁기 불가):
   ```js
   window.__all=[];const of=window.fetch;window.fetch=async function(...a){
     const r=await of.apply(this,a); r.clone().text().then(t=>window.__all.push(t)); return r;};
   ```
   조회 후 `JSON.parse(window.__all[window.__all.length-1])` → 291건 배열.
   필드: `da_acquire`(취득일 YYYYMMDD) · `nm_fixast`(자산명) · `mn_base`(취득가액) ·
   `mn_ftdepsum`(전기말상각누계) · `rt_depre`(상각률) · `cd_acctit`/`nm_acctit`(계정과목)

⚠️ **거래처 검색창의 한글 입력은 첫 글자가 맨 뒤로 밀린다**(`아아이비` → `아이비아`).
거래처는 **코드로 검색**할 것. 코드는 거래처 코드도움 다이얼로그를 한 번 열면
전체 마스터(1,984건)가 응답으로 통째로 떨어지므로 거기서 찾는다.
