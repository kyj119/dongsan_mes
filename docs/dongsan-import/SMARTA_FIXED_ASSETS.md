# 감가상각 검증 — `미상각분감가상각계산`(SAAS0102) · 2026-08-05

## 왜 이 화면인가 (고정자산관리대장보다 낫다)

**상각대상금액(`mn_ctdepre1`)이 찍혀 있어 정액/정률을 구분할 수 있다.**

| 상각대상금액 | 상각방법 | 당기상각비 |
|---|---|---|
| = 취득가액 | **정액법** | 취득가 × `rt_depre` |
| = 미상각잔액 | **정률법** | (취득가 − 전기말누계) × `rt_depre` |

21기 실측 = 정률 224건 / 정액 24건. 대장(SAAS0107)만 보면 이 구분이 안 돼 **정액법 자산을
정률법으로 계산하는 오류를 못 잡는다**(실제로 구축물 5건이 그 상태였다).

**필드**: `mn_base_v`(취득가) · `mn_ftdepsum`(전기말누계) · `mn_ctdepsum`(당기말누계) ·
`rt_depre`(상각률) · `mn_ctdepre1`(상각대상금액) · `mn_codepre`(**당기상각비**) · `cd_acctit_v`(계정)

⚠️ **`[소계]`·`[합계]` 행이 섞여 있다**(`nm_fixast` 로 판별·249행 중 7행). 안 걸러내면 총액이 두 배가 된다.

메인화면 → 기수 선택(**기수 드롭다운은 메인화면에서만 열린다**) → 전체메뉴 → 고정자산 →
