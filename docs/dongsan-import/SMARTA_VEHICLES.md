## 금리·잔액·만기는 원장에서 **역산**했다

원리금균등은 월 원금이 `(1 + 월이자율)` 배로 늘어난다. 세무장부 253 원장이 **월 원금**을 주고
통장이 **정액 납입액**을 주므로 둘로 전부 풀린다.

```
r   = 원금[n] / 원금[n-1] - 1          (월이자율)
잔액 = (납입액 - 마지막 원금) / r
n   = -log(1 - 잔액·r/납입액) / log(1+r)   (잔여 회차)
```
