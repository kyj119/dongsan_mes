#### ★리치코엘 = 품목 공급처가 아니라 도금(진공증착) 임가공 업체

처음 `가로봉 → ACC-032 P단 깃대`로 연결했다가 **오연결로 판명되어 정정**했다. 실제 거래 구조는:

- **가로봉** = 가로기용 국기봉(ACC-042 막봉)을 도금 → **황금봉(ACC-041)**
- **수기봉 · 애기봉** = 수기용 막봉을 도금 → 황금봉. **애기봉 = 수기봉 동일물**이고 호칭만 혼용된다. `수기봉골드`도 같은 계열
- 즉 리치코엘 매입 31,664,500 은 **물건값이 아니라 도금 임가공비(외주가공비)**

라인 `notes` 에 "도금 임가공(진공증착) — 가로기용/수기용 막봉 → 황금봉"을 남겼고, `ACC-041`·`ACC-042` 품목 `description` 에도 도금 산출물/투입물 관계를 기록했다.

**주의**: 황금봉 원가는 `막봉 매입 + 도금 임가공비` 합산이다. `avg_unit_cost` 를 매입 라인만으로 계산하면 도금분이 물건값으로 잡히거나 이중계상될 수 있다. ACC-041 은 사양이 "가로기/가정용/수기대"로 용도가 한 품목에 묶여 있어 용도별 원가 분리도 안 된다 — 단가 트랙에서 별도 판단 필요.
