마감 스티커 A6 목업 (인쇄 테스트용)

A4 라벨지 4칸(105×148.5mm) 기준. 3장이 나옵니다 — 1·2장은 실제 사용 케이스, 3장은 기존 방식과의 비교입니다.

 일반 A4 시험인쇄 = 테두리 켬 / 실제 라벨지 = 테두리 끔

인쇄 설정 필수 — 용지 A4 · 배율 100%(실제 크기) · 여백 없음 · 배경 그래픽 켜기 · 컬러. 「페이지에 맞춤」이 켜져 있으면 mm 치수가 어긋나 검증이 무의미해집니다.

확인할 것 (일반 A4에 먼저 뽑아 라벨지에 겹쳐보세요)

  1. 칸 정합 — 105×148.5mm 칸이 라벨지 실물과 맞는지. 프린터 기종별 여백 편차가 있습니다.
  2. 썸네일 식별력 — 26×10mm(가로형) 그림으로 "어느 시안인지" 구분되는지. 이번 설계의 유일한 도박입니다. 안 되면 품목수를 줄이거나 A5로 키워야 합니다.
  3. 「실제」 칸 — 보드마카로 숫자 쓰기에 충분한 크기인지.
  4. 거래처명 가독성 — 마감대에서 집어들 때 바로 읽히는지.
  5. 3장 비교 — 방향 적응형이 정말 나은지, 아니면 그냥 정사각이 단순해서 나은지.

페이지 구성

  • 1장 — 가로형 4줄 / 세로형 3줄 / 가로형 1줄(대표시안 확대) / 정사각형 2줄
  • 2장 — 7줄 주문의 분할 출력(1/2 · 2/2) / 방향 혼재 주문 / 빈 칸
  • 3장 — 기존 방식(정사각 21×21 contain) vs 제안 비교
