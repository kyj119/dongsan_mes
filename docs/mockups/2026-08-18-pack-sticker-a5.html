마감 스티커 A5 목업 (인쇄 테스트용)

A4 가로 1장 = A5 라벨 2장입니다. 인쇄소에서 A4로 뽑아 가운데 재단선을 자르면 실물 A5가 됩니다. 운영 시에도 같은 출력물을 반 자르거나, 미리 재단해둔 A5 낱장을 급지하면 됩니다. 총 6장(라벨 11개).

인쇄 설정 필수 — 용지 A4 · 방향 가로 · 배율 100%(실제 크기) · 여백 없음 · 배경 그래픽 켜기 · 컬러. 「페이지에 맞춤」이 켜져 있으면 mm 치수가 어긋나 검증이 무의미해집니다.

확인할 것

  1. 썸네일 식별력 — 표 안 38×14mm(가로형)로 시안이 구분되는지. 이번 설계의 핵심입니다.
  2. 「실제」 칸 — 보드마카로 숫자 쓰기에 충분한지(21~35mm 폭).
  3. 크기 감각 — A5가 현수막 묶음·박스에 붙이기 적당한지, 너무 크지 않은지.
  4. 품목명 잘림 — 가로형 라벨에서 품목명이 잘리지 않는지. 시안 열을 넓힌 대가입니다.
  5. 마지막 장 비교표 — 방향 적응형이 정말 나은지.

담긴 케이스

  • 현수막·봉제 계열(행별 시안) — 가로형 4줄 / 세로형 3줄 / 가로형 1줄 / 정사각형 2줄 / 방향 혼재 4줄 / 9줄 → 자동 분할(1·2 / 2)
  • 시트·재단 계열(판 전체 이미지) — 판 1장 / 판 3장(이미지 30개 → 10·10·10 → 박스 15·15) / 판 6장(한 장에 어디까지 담기는지)
  • 마지막 = 정사각 슬롯 vs 방향 적응형 비교표

시트·재단 라벨에서 특히 볼 것

  1. 판 이미지 식별력 — 판이 3장·6장일 때 조각 번호가 읽히는지. 안 읽혀도 판을 구분할 수 있으면 목적은 달성입니다.
  2. 박스 번호 — 박스 2 / 4 가 붙인 채로 멀리서 읽히는지. 출력 시 박스 수를 입력하면 N부가 자동 연번으로 나옵니다(손기입 아님).
  3. 판 6장 — 최소변이 12mm 아래로 내려가면 라벨을 자동으로 나눕니다(장 1/2). 그 경계가 적절한지.
  4. 「장 n/m」 과 「박스 n/N」 이 헷갈리지 않는지 — 서로 다른 수이고 한 장에 같이 나옵니다.
