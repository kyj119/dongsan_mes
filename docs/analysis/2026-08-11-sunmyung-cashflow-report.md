## 3. 제외한 항목과 근거

### 우회발행 94,812,300 — 선명 매출이 아니다

오케이애드공사·대운애드빌 매출이 **동산기획과 선명 양쪽에 같은 금액**으로 존재한다.
동산기획은 실제 작업 건별로 쪼개져 있고, 선명은 **매월 1~2건으로 뭉친 동일 금액**이다.
대금은 선명 통장으로 들어왔고 **입금 합계가 발행액과 원 단위까지 일치**한다.

## 4. 적자의 구조

| 원인 | 근거 | 규모 |
|---|---|---|
| **원가율 77.9%** | 매입 6억 2,354만 / 매출 8억 79만 | 구조적. 이것만으로 총이익률 22.1% |
| **인건비 25.4%** | 1월 2,671만 → 7월 3,981만 (+49%) | 총이익률을 넘어선다 |
| **공장 이전(4월)** | 보증금 1억 + 중개수수료 762만 + 월세 770만→1,100만 | 일시 1억 + 경상 월 330만 증가 |
| **카드 경상비 증가** | 1월 147만 → 7월 2,451만(세금 1,133만 포함) | 경상분 월 1,300만 수준 |

**핵심은 원가율이다.** 인건비를 0으로 만들어도 총이익률 22.1%로는
현재 규모의 고정비를 감당하지 못한다. 매출 확대가 아니라 **단가·원가 재검토**가 먼저다.
