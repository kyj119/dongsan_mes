| 품목 | 코드 | 라인 | 매출 |

| **계** | | **78** | **41,917,000** |

### 막힌 지점 — 데이터가 아니라 **입력**이 없다

간판 BOM 자체는 있다(`product_materials`, 6개 제품 26행: 채널 7종·조명프레임 7종·비조명 6종·돌출 4종).
문제는 그 BOM 이 **면적·둘레·폭 기반**이라는 것이다 — `PER_AREA_SHEET`·`PER_PERIMETER`·`PER_AREA`·`PER_LED`·`PER_WIDTH`.

**그런데 판매 78라인 전부 가로·세로가 0이다.** 치수가 없으면 자재량이 안 나오고, 자재량이 없으면 원가가 안 나온다.

| 필요한 것 | 현재 | 없으면 |
|---|---|---|
| **① 주문 라인 치수(가로×세로)** | **78/78 라인 0** | BOM 이 면적·둘레 기반이라 자재량 계산 불가 — **최우선** |
| **② 자재 단가** | 후렉스(FLEXN-130·FLEXL-130)·까치발(ACC-029) **avg_unit_cost = 0** | 프레임간판(1,321만) 원가 산출 불가 |
| **③ 시공·설치비 기준** | 축 자체가 없음 | 간판은 설치 비중이 큰데 BOM 은 자재만 담는다 |
| ④ SIGN-SCS·SIGN-ETC BOM | 없음 | 354만분은 표준 원가 불가 |

**①만 채우면 채널간판(2,509만)과 조명프레임(415만)은 바로 원가가 나온다** — 그쪽 자재 단가는 이미 있다.
②까지 채우면 간판 매출의 **96%(4,032만)**가 커버된다.

### 대안 — 치수 없이도 지금 할 수 있는 것

7월 간판 매입을 거래처 기준으로 역산할 수 있다. 7월에 새로 등장한 간판 자재 매입처
(한들대전·화성스틸·진보스텐 등)의 매입액을 간판 원가로 배부하면 **전체 마진율의 근사치**는 나온다.
품목별로는 못 나눈다.
