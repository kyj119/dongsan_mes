# 문자·MMS 발송 지침 (광고성 정보 규제)

> 대상: 메시지 발송을 하는 모든 직원
> 근거: 정보통신망법 §50, 시행령 §61~62의3
> 최종 갱신: 2026-07-28

---

## 0. 한 줄 요약

**할인·이벤트·신제품처럼 "사달라"는 내용이 한 줄이라도 들어가면 [광고 발송] 탭으로 보낸다.**
그 외 주문·시안·배송·청구 안내는 평소대로 [대량 발송]·[새 발송]을 쓴다.

---

## 1. 왜 지켜야 하나

광고 문자를 규정 없이 보내면 **과태료 최대 3,000만원**이 나옵니다. 이 책임은 문자를 보낸 직원이 아니라
**사업자(동산기획)에게 귀속**됩니다. 문자는 발송 후 취소가 불가능하고, 발송 이력이 그대로 증거로 남습니다.

그래서 MES는 규칙을 문서로만 두지 않고 **시스템이 막도록** 만들었습니다.
아래 내용은 "시스템이 무엇을 대신해 주는가"를 아는 데 필요한 만큼만 담았습니다.

---

## 2. 정보성 vs 광고성 — 판단표

| 내용 | 판정 | 어디서 보내나 |
|---|---|---|
| 주문 접수·변경 안내 | 정보성 | 대량 발송 / 새 발송 |
| 시안 확인 요청 | 정보성 | 카드 상세 → **[시안 발송]** |
| 배송·출고·송장 안내 | 정보성 | 대량 발송 / 새 발송 |
| 세금계산서·거래명세서·미수금 안내 | 정보성 | 대량 발송 / 새 발송 |
| 휴무·이전·연락처 변경 공지 | 정보성 | 대량 발송 |
| **단가 인상** 안내 | 정보성 | 대량 발송 |
| **단가 인하·할인** 안내 | **광고성** | **광고 발송** |
| 이벤트·사은품·프로모션 | **광고성** | **광고 발송** |
| 신규 장비·서비스 소개 | **광고성** | **광고 발송** |
| 명절 인사 (인사말만) | 정보성 | 대량 발송 |
| 명절 인사 + 작업물 사진·홍보 | **광고성** | **광고 발송** |

### 헷갈릴 때의 기준 하나
> **"이 문자를 받고 주문이 늘기를 기대하는가?"**
> 그렇다면 광고성입니다. 인사말이 90%여도 유인 문구가 한 줄 있으면 **전체가 광고**로 판정됩니다.

### 자주 하는 오해
- ❌ "우리 거래처니까 괜찮다" → 거래처여도 `(광고)` 표기와 수신거부 안내는 **면제되지 않습니다**.
  (거래처에게 면제되는 것은 *사전 동의*뿐이고, 그것도 최근 6개월 거래에 한합니다)
- ❌ "이미지에만 넣으면 된다" → **이미지 내용도 판정 대상**입니다. 오히려 더 명확한 증거가 됩니다.
- ❌ "(광고)를 이미지에 넣었다" → **무효**입니다. 본문 텍스트 맨 앞에 있어야 합니다.

## 3. [광고 발송] 탭 사용법 (관리자 전용)

`메시지 관리 → 광고 발송` 탭. **ADMIN 계정에만 보입니다.**

### 시스템이 자동으로 처리하는 것 (끌 수 없음)
| 항목 | 동작 |
|---|---|
| `(광고)` 표기 | 본문·제목 맨 앞에 자동 삽입 |
| 수신거부 안내 | 본문 끝에 `무료수신거부 <링크>` 자동 첨부 (수신자마다 다른 링크) |
| 수신거부자 제외 | 거부 등록된 번호는 대상에서 자동 제거 |
| 6개월 필터 | 최근 6개월 내 거래가 없는 거래처는 자동 제외 |
| 야간 차단 | 21:00~08:00 발송·예약 모두 거부 |
| 채널 제한 | 단문(SMS) 사용 불가 — 장문(LMS)·MMS만 |

### 절차
1. 채널 선택 (장문 / MMS)
2. 수신자 선택 — 그룹 또는 직접 입력(엑셀 붙여넣기)
3. 제목·본문 작성 (`#{거래처명}` 등 변수 사용 가능)
4. **[대상 확인]** — 실제 발송 인원과 제외 내역을 계산합니다. **이걸 눌러야 발송 버튼이 열립니다.**
5. 제외 내역 확인 후 **[발송]**

### [대상 확인]에서 보게 될 제외 사유
| 표시 | 뜻 | 조치 |
|---|---|---|
| 수신거부 | 거부 의사를 밝힌 번호 | 발송 불가 (법적 의무) |
| 6개월 경과 | 마지막 거래가 6개월 이전 | 광고 발송 불가. 거래를 다시 트고 나서 가능 |
| 거래이력 없음 | 거래처를 못 찾음 | 번호가 거래처에 등록돼 있는지 확인 |
| 번호 오류 | 형식 불량 | 명단 수정 |

## 4. 수신거부 처리

### 고객이 링크를 눌렀을 때
자동으로 처리됩니다. 직원이 할 일은 없습니다.

### 고객이 전화로 "문자 그만 보내라"고 할 때
`광고 발송 탭 → 수신거부 명단 → [직접 등록]`에 번호를 넣습니다. **이건 법적 의무이고 미루면 안 됩니다.**

### 주의
수신거부한 고객에게도 **주문·시안·배송 같은 거래 관련 안내는 계속 보낼 수 있습니다.**
수신거부는 광고성 정보에만 적용됩니다.

## 5. 일반 발송에서 차단당했을 때

대량 발송 탭에서 이런 메시지가 나오면:

> 광고성 문구가 포함되어 있습니다: 할인, 특가

두 가지 중 하나입니다.

1. **정말 광고인 경우** → [광고 발송] 탭에서 보내세요(관리자에게 요청).
2. **오탐인 경우** (예: "무료배송 안내"가 걸림) → 관리자가 `광고 발송 탭 → 금지어`에서 해당 단어를
   삭제할 수 있습니다. 업종 문구에 맞게 조정하세요.

## 6. MMS(이미지 첨부) 추가 주의

- **건당 100원**입니다(장문 35원의 약 3배). 1회 50건 상한이 걸려 있습니다.
- 이미지에 **가격표·타 고객 작업물·포트폴리오를 넣지 마세요.** 정보성으로 보내려던 문자가 광고로 뒤집힙니다.
- 시안 확인은 카드 상세의 **[시안 발송]** 버튼을 쓰세요. 문안이 자동으로 만들어지고 주문번호가 들어가
  정보성임이 명확해집니다. 이 문안은 지우지 말고 그대로 쓰는 것이 안전합니다.

## 7. 개발자용 메모

- 구현: `src/routes/messagesAd.ts`(발송·대상 판정), `src/services/messageCompliance.ts`(공통 헬퍼),
  `src/routes/publicUnsubscribe.ts` + `src/pages/unsubscribe.ts`(수신거부), 마이그레이션 `0479`.
- 6개월 판정은 **3사 전체 `orders`** 기준이다(`entityFilter` 미적용은 의도된 것 — 거래처는 3사 공유 자산).
- 발송 로그 `kakao_send_logs.message_type` = `INFO` | `AD`. 분쟁 시 정보성 입증 근거.
- ⚠️ **로그에 이미지가 저장되지 않는다**(`alt_content`엔 용량만). 광고 분쟁의 핵심 증거는 이미지인데
  현재는 재현할 수 없다. 판촉을 본격화하면 R2 키 저장 보완이 필요하다.
- ⚠️ 테스트할 때 `/api/messages/ad/send`·`/send-bulk`를 호출하면 **실제 발송이 시도된다**.
  검증은 `/api/messages/ad/preview`만 쓸 것.
