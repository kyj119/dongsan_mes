# 배송 알림 — 「언제 보내나」 설계 (2026-09-18)

> 결론부터: **출고 처리 시점에 일괄로 보낼 수 없다.** 그 시점엔 송장이 없기 때문이다.
> 대신 **배송수단이 시점을 정한다** — 송장이 필요 없는 건은 출고 즉시, 필요한 건은 송장 저장 때.

## 1. 판단 근거 (전부 prod 실측)

| 사실 | 값 | 설계에 주는 제약 |
|---|---|---|
| 출고 처리 경로 | 10개 (사람이 쓰는 건 3개: 카드 보드 · 주문 목록 일괄 출고 · 출고/배송) | 한 창구에 모을 수 없다 |
| 카드 보드 = 인쇄현장 | `/shipments` 권한 없음 | **발송 판단 주체가 아니다** |
| 출고 시점의 송장 | 없음 (택배·화물은 나중에 입력) | 즉시 발송하면 `#{송장번호}` 가 빈칸 |
| 송장 불필요 건 | 방문수령 583 · 직배 196 · 직접배송 192 · 퀵 25 = **996건(57%)** | 이건 **즉시가 맞다** |
| 송장 필요 건 | 대신화물 299 · 한진 226 · 대신택배 60 = **585건(34%)** | 이건 **나중이 맞다** |
| 승인 템플릿 | 대신화물 출고 · 대신택배 출고 · 방문 수령 준비 완료 (3개) | 한진(226건)은 **문자로** 보내야 한다 |
| 거래처 휴대폰 보유 | 약 82% | 나머지는 「연락처 없음」이지 「미발송」이 아니다 |
| 중복 발송 | 성공 로그 있으면 멱등 skip | 자동·수동 병행해도 두 번 안 간다 |
| 출고 취소 | 실제로 일어난다(P22) | **보낸 문자는 되돌릴 수 없다** — 자동은 신중히 |
| 비용 | 알림톡 7원 · 문자 15 · 장문 35 (VAT 별도), 잔액 201,884원 | 월 최대 14,350원 — **제약이 아니다** |

## 2. 시점 — 둘뿐이고, 배송수단이 고른다

```
T1  출고 확정(주문 SHIPPED)          → 송장 불필요 건 (방문수령·직배·직접배송·퀵)
T2  박스·송장 저장(확정 대기에서 빠짐) → 송장 필요 건 (대신화물·대신택배·한진)
```

**「출고 처리하면서 모달로 함께 발송」은 T1 에만 성립한다.** T2 건을 그 자리에서 보내면 송장 없는 알림이 된다.

## 3. 화면별 결정

### ① 주문 목록 「일괄 출고」 — 확인창에 체크박스 하나
```
5건의 주문을 일괄 출고 처리하시겠습니까?
  · 즉시 알림 가능: 3건 (방문수령 2 · 퀵 1)
  · 송장 입력 후 발송: 2건 (한진택배) → 확정 대기로 이동합니다
  [ ] 출고와 함께 알림 발송  (알림톡 3건 · 21원)
```
- **기본 꺼짐**으로 시작한다(병행 초기). 안정되면 기본 켬으로 바꾼다.
- 체크해도 **T1 건만** 나간다. T2 건은 확정 대기로.
- 일괄인데 문구 확인 없이 보내도 되는 이유 = T1 문구는 「준비 완료」 고정이고 변수가 고객명·품목뿐이다.

### ② 카드 보드 출고 — **발송 UI 없음**
인쇄현장은 판단 주체도, 권한 보유자도 아니다. 전부 확정 대기로 흘려보낸다.
(현장이 「알림 나갔나요」를 물을 일이 없도록, 카드 화면에는 아무 표시도 하지 않는다.)

### ③ 확정 대기 — **여기가 정본 창구**
행의 버튼을 둘로 나눈다.

| 버튼 | 동작 |
|---|---|
| **확정 + 알림** | 박스·송장 저장 → 발송 모달 → 발송. 미발송 배지가 그 자리에서 사라진다 |
| 확정만 | 지금 동작 그대로(저장만) |

### ④ 섹션별 일괄 발송(기존 화면) — 그대로 둔다
문구를 손보거나 골라 보낼 때 쓰는 창구. 없애지 않는다.

## 4. 발송 모달의 내용

```
┌ 배송 알림 발송 ─────────────────────────┐
│ 받는 곳   (주)하우사인  010-1234-5678        │
│ 채널      ● 알림톡(대신택배 출고)  ○ 문자      │
│ 본문                                        │
│   하우사인님, 동산기획입니다.                 │
│   ■ 품목: 현수막 외 2건                      │
│   ■ 배송: 대신택배 / 송장 1234567890         │  ← 송장이 실제로 들어갔는지 눈으로 본다
│ 비용      알림톡 7원                          │
│              [보내지 않고 확정]  [발송]       │
└─────────────────────────────────────────┘
```
- **본문 미리보기가 핵심이다.** 변수 치환 뒤를 보여줘 빈 `#{송장번호}` 가 그대로 나가는 사고를 막는다.
- 승인 템플릿이 없는 배송수단(한진)은 **자동으로 문자 선택** + 「이 배송수단은 알림톡 템플릿이 없어 문자로 나갑니다」 한 줄.
- 휴대폰이 없으면 모달을 열지 않고 「연락처 없음」으로 확정만 진행한다.

## 5. 안 하기로 하는 것 (되돌릴 조건 포함)

| 안 함 | 이유 | 되돌릴 조건 |
|---|---|---|
| 카드 보드에 발송 UI | 권한·판단 주체가 아니다 | 인쇄현장이 배송까지 맡게 되면 |
| 출고 즉시 택배 알림 | 송장이 없다 | 송장을 출고 전에 받는 체계가 생기면 |
| 자동 발송 전면 개시 | 문구·대상 근거가 아직 로그에 없다 | 수동 2주 로그가 쌓이면 |
