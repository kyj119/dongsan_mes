# 배송 알림 — 「언제 보내나」 설계 (2026-09-18)

> 결론부터: **배송수단이 시점을 정한다.** 승인 템플릿 실측 결과 **송장을 기다려야 하는 건 한진택배뿐**이고,
> 나머지 알림 대상은 **출고 즉시** 보낼 수 있다. 직배·퀵·용차는 **아예 대상이 아니다**(직접 가져다 준다).
>
> **갱신 2026-09-18 저녁** — ①승인 템플릿 4건 본문 실측 ②실발송 테스트 4건 도착 확인
> ③용준님 결정(직배·퀵·용차 미발송 · 거래처 터미널 고정) 반영. 아래 표를 그에 맞게 다시 썼다.

## 2. 시점 — 둘뿐이고, 배송수단이 고른다

```
T1  출고 확정(주문 SHIPPED)          → 방문수령 · 대신화물 · 대신택배  (942건 54%)  알림톡
T2  박스·송장 저장(확정 대기에서 빠짐) → 한진택배                      (226건 13%)  문자
없음 직배 · 직접배송 · 퀵 · 용차       → 보내지 않는다                  (413건 24%)
```

**「출고 처리하면서 모달로 함께 발송」은 T1 에 성립하고, 그 비중이 54% 다.**
T2(한진)를 그 자리에서 보내면 송장 없는 문자가 된다.

★**「대상 아님」과 「미발송」을 반드시 다른 상태로 둔다.** 섞으면 확정 대기 목록이
영영 안 줄어드는 건들로 찬다(실측: 21건 → 8건).

## 3. 화면별 결정

### ① 주문 목록 「일괄 출고」 — 확인창에 체크박스 하나
```
5건의 주문을 일괄 출고 처리하시겠습니까?
  · 즉시 알림 가능: 3건 (방문수령 2 · 퀵 1)
  · 송장 입력 후 발송: 2건 (한진택배) → 확정 대기로 이동합니다
  [ ] 출고와 함께 알림 발송  (알림톡 3건 · 21원)
```
- **기본 꺼짐**으로 시작한다(병행 초기). 안정되면 기본 켬으로 바꾼다.
- 체크해도 **T1 건만** 나간다. T2(한진)는 확정 대기로, 대상 아님은 아무것도 안 한다.
- 일괄인데 문구 확인 없이 보내도 되는 이유 = T1 템플릿의 변수가 고객명·품목·날짜(+터미널)뿐이고
  **전부 출고 시점에 확정되어 있다**(송장처럼 나중에 오는 값이 없다).

### ② 카드 보드 출고 — **발송 UI 없음**
인쇄현장은 판단 주체도, 권한 보유자도 아니다. 전부 확정 대기로 흘려보낸다.
(현장이 「알림 나갔나요」를 물을 일이 없도록, 카드 화면에는 아무 표시도 하지 않는다.)

### ③ 확정 대기 — **여기가 정본 창구**
행의 버튼을 둘로 나눈다.

| 버튼 | 동작 |
|---|---|
| **확정 + 알림** | 박스·송장 저장 → 발송 모달 → 발송. 미발송 배지가 그 자리에서 사라진다 |
| 확정만 | 지금 동작 그대로(저장만) |

### ④ 섹션별 일괄 발송(기존 화면) — 그대로 둔다
문구를 손보거나 골라 보낼 때 쓰는 창구. 없애지 않는다.

## 4. 발송 모달의 내용

```
┌ 배송 알림 발송 ─────────────────────────┐
│ 받는 곳   (주)하우사인  010-1234-5678        │
│ 채널      ● 알림톡(대신택배 출고)  ○ 문자      │
│ 본문                                        │
│   하우사인님, 동산기획입니다.                 │
│   ■ 품목: 현수막 외 2건                      │
│   ■ 배송: 대신택배 / 송장 1234567890         │  ← 송장이 실제로 들어갔는지 눈으로 본다
│ 비용      알림톡 7원                          │
│              [보내지 않고 확정]  [발송]       │
└─────────────────────────────────────────┘
```
- **본문 미리보기가 핵심이다.** 변수 치환 뒤를 보여줘 빈 `#{송장번호}` 가 그대로 나가는 사고를 막는다.
- 승인 템플릿이 없는 배송수단(한진)은 **자동으로 문자 선택** + 「이 배송수단은 알림톡 템플릿이 없어 문자로 나갑니다」 한 줄.
- 휴대폰이 없으면 모달을 열지 않고 「연락처 없음」으로 확정만 진행한다.
