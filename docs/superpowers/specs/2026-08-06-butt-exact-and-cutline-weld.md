# 맞붙임 = mm 배치 + 공유 변 단일 출력 — 설계

> 2026-08-06 · 용준님 지적으로 **설계를 한 번 갈아엎었다**(아래 §2). 관련 = `2026-07-31-cut-file-panel.md`

## 1. 문제

맞붙임(여백 0 · 간격 0)의 목적은 **재단을 한 번만** 하는 것이다. 두 지점에서 깨진다.

| # | 증상 | 원인 |
|---|---|---|
| ① | 조각이 최대 1mm 어긋난다 | 배치가 **픽셀 격자**에 양자화된다 |
| ② | 붙여도 DXF 에 선이 두 줄 | 칼선이 **조각마다 닫힌 경로**라 좌표가 같아도 별개 엔티티다 |

## 2. ★도구를 잘못 골랐다 (2026-08-06 재설계)

처음엔 "격자를 곱게" → "겹친 선분을 오차로 찾아 용접" 순으로 잡았다. **둘 다 우회로였다.**

- **픽셀 격자는 일러의 제약이 아니라 우리가 만든 제약**이다. 일러는 `position` 에 부동소수를 그대로 받는다.
  맞붙임에 필요한 건 탐색이 아니라 산수(`x = 0, w1, w1+w2 …`)이고, 그건 **래스터 네스터를 안 거치면 된다.**
  이형 네스팅이 안 돼서 생긴 오차가 아니라, **이형 네스터에 사각형 문제를 밀어 넣어서** 생긴 오차다.
- **어느 변이 공유되는지는 배치를 만든 우리가 이미 안다.** 그걸 나중에 오차 비교로 다시 찾아낼 이유가 없다.
  → 사후 용접이 아니라 **처음부터 한 번만 그린다**. 허용오차라는 개념 자체가 사라지고,
  "안 붙은 선을 잘못 합쳐 재단 위치가 옮겨지는" 위험도 함께 사라진다.

일러 자체 기능으로는 안 된다:
| 기능 | 왜 |
|---|---|
| Pathfinder **Unite** | 공유 변을 **지운다** — 그 선이 있어야 조각이 떨어진다 |
| Pathfinder **Outline** | 완전 중복까지 지운다는 보장이 없다 |
| 메뉴 명령 전반 | 네스팅 중 모달이 뜨면 그 자리에서 멈춘다(2026-08-04 실측, `userInteractionLevel` 로 막아 둔 이력) |
| Smart Guides·정렬 | 사람이 손으로 놓을 때만 |

## 3. 설계

### 조건
맞붙임(여백 ≤0 · 간격 ≤0) **그리고** 모든 조각이 **직사각에 가까움**(잉크가 자기 bbox 를 거의 채움).
하나라도 아니면 기존 래스터 네스팅으로 간다 — 이형끼리는 붙여도 칼선이 애초에 안 맞는다.

### ① mm 배치 (`js/butt.js` · `packRects`)
선반(shelf) 배치. 높이 내림차순 정렬 → 행을 왼→오른쪽으로 채우고, 행 높이는 그 행의 최댓값.
간격 0 이므로 행끼리도 맞닿는다. 좌표는 **mm 부동소수**이고 인접 변은 **같은 값**이 된다(구성상 동일).

### ② 공유 변 단일 출력 (`js/butt.js` · `cutSegments`)
사각 경계를 선분으로 모아 **좌표가 같은 축으로 묶고 구간을 합집합**한다.
- 세로 = x 가 같은 것끼리 y 구간 합집합 · 가로 = y 가 같은 것끼리 x 구간 합집합
- 맞닿은 구간(끝점 일치)도 합친다 → 재단기가 **끊지 않고 한 번에** 지난다
- 오차 판정 없음. 좌표가 구성상 같으므로 **정확 일치**로만 묶는다

2×2 동일 조각이면 사각형 4개(선분 16)가 아니라 **세로 3 + 가로 3 = 6**.

## 4. 검증

| 게이트 | 내용 |
|---|---|
| `cut:butt` (신설) | 2×2 동일 → 6선분 · 2종 혼합 → 손계산과 일치 · 안 맞닿은 변은 안 합쳐짐 · 전 조각 겹침 0 |
| `cut:nest` | 이형 배치 회귀 0 |
| 실기 | 2종 이상 섞인 맞붙임 1건을 DXF 까지 → **재단기가 한 번만 지나가는지** |

마지막이 진짜 판정이다.

## 5. 순서

1. **엔진 + 하네스**(`js/butt.js`, `cut:butt`) — 순수 계산, 일러 없이 전부 검증된다
2. **배선** — 맞붙임 판정 → params 에 선분 내보내기
3. **호스트** — 열린 선분 그리기(새 행 타입). 축2라 전 PC 즉시 반영이므로 실기 확인 후

## 6. 열린 것

- 직사각 판정 임계(잉크/bbox 비율) — 실파일로 정한다
- **용접하면 닫힌 경로가 열린 폴리라인이 된다** — 재단기는 자르지만 레이어 규약·검수 습관과 어긋날 수 있어 실측 필요
- 회전 허용 시 직사각 판정·패킹 상호작용
- 벡터 칼선 경로(`useVec`)는 좌표를 패널이 갖지 못한다 → 맞붙임에선 **래스터로 유도**하고 알린다
