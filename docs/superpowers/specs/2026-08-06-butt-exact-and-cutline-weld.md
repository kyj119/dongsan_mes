# 맞붙임 정확 배치 + 칼선 용접 — 설계

> 2026-08-06 · 용준님 지적에서 출발. 관련 = `2026-07-31-cut-file-panel.md` · memory `design-irregular-nesting`

## 1. 문제

맞붙임(여백 0 · 간격 0)의 목적은 **재단을 한 번만** 하는 것이다. 지금은 두 지점에서 깨진다.

| # | 증상 | 원인 |
|---|---|---|
| ① | 조각이 최대 1mm 어긋난다 | 배치가 **픽셀 격자**에 양자화된다. 격자를 곱게 하면 굽기가 1억 px 로 커져 몇 분 걸린다 |
| ② | 붙여도 DXF 에 선이 두 줄 | 칼선이 **조각마다 닫힌 경로**다. 좌표가 같아도 별개 엔티티라 재단기가 두 번 지난다 |

**②는 ①을 완벽히 고쳐도 남는다.** 둘을 같이 고쳐야 목적이 성립한다.

> ⚠️ 격자 해상도를 올리는 방향은 막다른 길이다 — 근사를 곱게 만드는 것이지 일치를 만드는 게 아니다.
> 2026-08-06 에 32M px 예산으로 타협했지만, 맞붙임에서는 그 타협 자체가 무의미하다.

## 2. 전제 (용준님 확인, 2026-08-06)

- 맞붙임 대상은 **서로 다른 직사각 여러 종이 섞이는 경우가 많다** → 단순 타일링으론 부족, 패커가 필요하다
- 칼선 용접은 **맞붙임뿐 아니라 겹치면 항상** 적용한다

## 3. 설계

### P1 — 칼선 용접 (항상 적용)

**어디서**: 패널. 칼선은 `pieceCutLines()` 가 **mm 좌표 폴리라인**으로 만들어 `P`/`B` 줄로 내보낸다.
호스트는 받은 것을 그릴 뿐이라, 용접은 params 를 쓰기 **직전**에 한다. 하네스로 검증 가능하다(프로젝트 원칙).

**무엇을**: 같은 자리에 놓인 **직선 선분**을 하나로 합친다.
- 대상 = 축정렬·동일선상(collinear) 이면서 구간이 겹치는 선분
- 결과 = 2×2 명함이면 사각형 4개가 아니라 **세로선 3 + 가로선 3**

**허용오차 = 아주 작게(0.05mm 이하).**
> ⚠️ 느슨하게 잡으면 **붙지 않은 칼선까지 합쳐 재단 위치가 옮겨진다**. 용접은 "이미 같은 자리"를
> 정리하는 것이지 "가까우니 맞춰주는" 기능이 아니다. 그래서 P2 없이 P1만 있으면 거의 발동하지 않는다 —
> 그게 맞는 동작이다.

**곡선(`B` 줄)은 대상 외.** 베지어가 정확히 겹치는 경우는 실무에 없고, 근사 비교는 위험만 크다.

**벡터 칼선 경로(`useVec`)는 이번 범위 밖.** 그 경로는 일러가 조각마다 오프셋해 만들어 패널이 좌표를
갖지 못한다 → 맞붙임에서는 **래스터 칼선으로 유도**하고 그 사실을 화면에 알린다.

### P2 — 맞붙임 직사각 패킹 (연속 좌표)

**조건**: 맞붙임 + 모든 조각이 **직사각에 가까움**(마스크 잉크가 자기 bbox 를 거의 채움).
하나라도 아니면 기존 래스터 네스팅으로 간다 — 이형끼리는 붙여도 칼선이 애초에 안 맞는다.

**무엇을**: 픽셀이 아니라 **mm 부동소수**로 배치한다. MaxRects 계열(연속 좌표).
- 인접 변의 좌표가 **구성으로** 같아진다 → P1 이 그걸 한 줄로 합친다
- 배치 격자 해상도가 **무관해진다** → 굽기를 곱게 할 이유가 사라져 속도도 같이 해결된다

**참고**: Jukka Jylänki "A Thousand Ways to Pack the Bin"(MaxRects·Skyline·Guillotine 서베이) ·
potpack(Mapbox, JS) · maxrects-packer(JS) · rectpack(Python, 대조군).
repo 전례 = 폐기한 웹 모아찍기의 `iaeMaxRectsPack`(연속 좌표 MaxRects, git 히스토리).

## 4. 검증

| 게이트 | 내용 |
|---|---|
| `cut:weld` (신설) | 2×2 타일 → 선분 수가 **6**(3+3)이지 16 이 아니다 · 안 붙은 조각은 **안 합쳐진다** · 허용오차 밖은 유지 |
| `cut:nest` | 기존 이형 배치 회귀 0 |
| `cut:smoke` | 맞붙임에서 벡터 칼선이 아니라 래스터로 가는지 · 알림 문구 |
| 실기 | 2종 이상 섞인 맞붙임 1건을 DXF 까지 → **재단기가 한 번만 지나가는지** |

마지막 항목이 진짜 판정이다. 나머지는 거기 도달하기 위한 것이다.

## 5. 순서

**P1 먼저.** 용접은 단독으로도 의미가 있고(겹친 칼선이 있으면 언제나), P2 의 결과를 받아낼 그릇이다.
P2 를 먼저 하면 "정확히 붙었는데 여전히 두 줄"이라 확인이 안 된다.

## 6. 열린 것

- 직사각 판정 임계(잉크/bbox 비율) — 실파일로 정해야 한다
- 회전 허용 시 직사각 판정과 패킹 상호작용
- 용접 후 **닫힌 경로가 열린 폴리라인**이 된다 → DXF·일러 양쪽에서 문제 없는지 실측 필요
  (재단기는 열린 경로도 자르지만, 레이어 규약·검수 습관과 어긋날 수 있다)
