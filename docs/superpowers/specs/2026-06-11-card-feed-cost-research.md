## 권장 로드맵 (재개 시)
1. 전 카드 알림 가입(~9천/월) + 수신→파서→`POST /api/card-expenses` + 홈택스 월 대조 보정 → 유료 조회 해지 (구축 1~2세션)
2. 카드사 통폐합 8→2~3곳 — 선정 기준에 "공식 API 제공"(우리카드 등) 포함 여부 미정
3. API 제공사 수렴 시 파싱→공식 API 전환 = 0원 종착
