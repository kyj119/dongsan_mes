| 질문 | 판단 |

## 1. 실측 (prod 2026-01~09)

| 분류 | 건 | 예 | 과금 |
|---|--:|---|---|
| 진짜 3축 — 큐브박스·큐브간판 | 3 | `30x205x22cm` 21만 · `1700x300x100mm` 19만 | FIXED 손 단가 |
| 진짜 3축 — 입간판(스틸·스텐·각관) | 3 | `600x1000x1500` 48만 · `800x500x2200` 18만 | FIXED 손 단가 |
| 진짜 3축 — 갈바 프레임 | 3 | `3660x150x100mm` 28만 | FIXED 손 단가 |
| 오타 | 5 | `600*9*0` `700**90` `122**232` | 2축(현수막·포맥스) |
| 나열·장수 접미 | ~8 | `244*122, 100*122` · `66x367x3장` | 2축 |

- 진짜 3축 **9건 / 8개월 ≈ 월 1건**, 전부 간판 계열(선명), 전부 건별 견적, 7만~48만원. 아크릴 **박스** 자체는 1건.
- 아크릴 전체 ≈ 65라인 = **판재 2축 AREA**(`UV-ACR-xT`, 최소청구 0) + **가공 FIXED 라인**(레이져·도색·부착). 현 구조로 이미 돌아간다.
- 마스터: 포장박스·전기박스 = 규격별 품목 5개(`PKG-BOX-630440400`, 규격 텍스트 `630*440*400`) — 기성품·재고 단위라 **맞는 형태**. 주문제작에 이 방식을 쓰면 규격 = 마스터 폭발.

## 2. 왜 전개면적·부피 축을 만들지 않나

- **쓰는 라인이 없다** — 월 1건, 값은 사람이 정한다. 「면적 판정 = 규격 종류 수」 기준으로도 3축 품목은 규격이 전부 1회성 → FIXED 가 맞다.
- **비용이 정확히 한 세션이다** — `order_items.depth` 컬럼 · `orderLineAmount.ts`↔`calc.js` 산식 쌍 · `test:orderline` 픽스처 · 라인 스냅샷 · 견적 · 문서 표기 `W×D×H` · `displayUnitPrice`. 5곳이 늘어나고 아무 데도 안 쓰인다.
- **되돌릴 조건**(기록만): 같은 3축 품목이 **월 5건 이상** 반복되고 「두께별 ㎡단가 × 전개면적 + 접합비」 규칙이 실제 견적서에 쓰일 때 → `pricing_profile='SURFACE'` 로 그때 연다(`0323` 의 CHECK 집합 확장).

## 3. 표기 규칙 (확정 제안)

- 순서 **가로*깊이*높이**(`W*D*H`), 구분자 `*`(`x` 허용), 단위 접미 없으면 **cm**, mm 면 `mm` 접미(`1700x300x100mm`).
- 마스터 규격은 「그 계열에서 변하는 축」만(기존 규칙). 기성 박스는 규격별 품목 유지, 주문제작은 품목 1개(`SIGN-ACR-FAB` 등) + **라인 규격**.
- **3숫자 규격은 절대 2칸으로 뜯지 않는다** — `width/height` NULL, 텍스트 원문 보존. 이관 파서 `RX_WH` 는 이미 `^W*H$` 앵커라 안전하고, 오분해는 09-04 소급 분해에서 났다.
