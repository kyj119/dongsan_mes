## 0. 배경

### 이번 고찰의 출발점
현행 세션 루프(2026-07-16 P0)가 prod에 있으나, **실행 자체(F키)는 해결됐어도 세션루프 UX 전반**에 마찰이 남음. 정리된 5대 고민:
1. **로딩 지연** = JSX 실행→EPS 가공·저장 중 프리즈
2. **검토가 어려움** (가공 결과가 맞는지)
3. **가공 세팅**을 더 편하게
4. **저장 구조** — 오퍼레이터가 현장에서 남은 작업을 확인·소화
5. **완료물 ↔ MES 주문서 연동** — 특히 다량일 때

**결론**: "JSX 실행법"이 아니라 **일러 상주 작업대(팔레트) + 반자동 큐 + 확정 게이트 + 오퍼레이터 MES 현황**으로 세션루프를 재구성한다. 하류 데이터 계약(`designer_intakes`·work.ai·썸네일·임포지션)은 보존.

### 현장 사실 (2026-07-23 확인)
| 항목 | 사실 |
|------|------|
| 실행 | 테스트=Ctrl+F12, 실사용=**F키** 예정 |
| 다중 디자인 | **거의 모든 고객 파일이 다중 디자인**. 담김 형태 **혼합**(클리핑마스크·아트보드·맨그룹 제각각) → 사람은 판단 가능, **구조적 자동감지는 부정확** |
| 검토 | 가공 결과 **정밀 확인 필요**(특히 초기 롤아웃), **일러에서 확인** |
| 주문 존재 | 가공 시점에 **대개 없음**(파일 선행) |
| 오퍼레이터 | 파일을 **직접 열어 RIP 수동 삽입** + 앞으로 **MES 로그인→카드/생산→출고관리** |
| 저장 프리즈 | EPS 저장이 일러 단일스레드 동기 연산이라 멈춤 |

## 1. 확정 결정 (D1~D9)

| # | 결정 | 내용 · 근거 |
|---|------|------------|
| D1 | 폼 = **ScriptUI 도킹 팔레트** | 주문선택 UI 없고(파일선행) 정밀검토는 캔버스로 해결 → HTTPS 명분 없음. 기존 JSX 재사용·저리스크. CEP/UXP는 과투자(큐 UI가 답답하면 CEP 승격만 후보) |
| D2 | 다중 디자인 = **반자동 큐** | 혼합 컨테이너라 단독 자동감지는 과거 '추출 부정확' 재발. **사람 선택 + ExtractGroups 자동감지를 '첫 제안 시드'로**. 사람이 큐 앞에 있으니 시드 오류는 교정 대상 |
| D3 | 큐 교정 = **삭제·추가만** | 병합/분할은 **네스팅(판짜기) 영역**. 분할은 마스킹 씌워 재배치하는 방식이라 가공 큐 밖. (⚠️ D2 시드 내부의 `mergeRects` 겹침 병합은 **자동 전처리 휴리스틱**이지 사용자 병합 UI가 아님 — 별개) |
| D4 | 검토 = **일러 검토문서(아트보드) + 확정 게이트** | 큐 N디자인을 **하나의 검토 문서에 디자인당 아트보드**(design_0…N)로 가공 → 디자이너가 일러에서 **Fit All/줌/아트보드 이동**으로 확인(**다중 문서 안 엶**) → 확정 시에만 **아트보드별 EPS 배치 저장**. 반려 건엔 무거운 저장 안 함(#1 완화). ⚠️ 합산 타일이 **일러 대지 한도(~577cm/227in)** 초과 시(대형 현수막·평판) **순차(1디자인씩 full-size) 검토로 폴백** — 기본=순차, 소형만 전체보기 |
| D5 | 거래처 = **단일입력 + 상속** | 가공 시 1회 입력(자동완성)→주문서 상속. 2026-07-16 D5 유지 + **bf4c7a23 "거래처 제거" 갱신**. 자동완성은 **MES 거래처 리스트(에이전트 config 중계)에서 `clients.id` 해소** → intake `client_id` 저장(free-text 폴백) |
| D6 | 대기물 관리 = **작업 단위 그룹핑 + 내작업 로그인** | **원본 고객 파일 기준 `batch_key`**(전 디자인 공통, 배치 확정 시 부여)로 작업 그룹핑. ⚠️ `memo`(=출력 건별폴더, per-run 유니크 `mes-core.jsx:314`)는 디자인마다 달라 그룹핑 키로 부적합. 대기함 트레이 + **"내 작업"=MES 로그인 유저 id=`registered_by`** + 거래처·작업 스코핑 + 파일 그룹 일괄 프리필 |
| D7 | 오퍼레이터 = **MES 생산/출력 대기열** | **카드 상태 기반** "남은 작업" + 카드에 **Z: 파일경로 노출**→오퍼레이터가 열어 RIP. **기존 생산/카드 뷰 + /ship 파이프라인 재사용**(신규 화면 최소화) |
| D8 | 파일 = **스테이징 폴더 + 확정 시 조직폴더 이동** | 가공물은 `Z:\DESIGNS\IA-등록\<건별>\`(스테이징=SSOT)에 저장. **주문 확정(CONFIRMED) 시 `Z:\<archive>\<인쇄방식>\<YYYY>\<MM>\<DD>\<order_number>\`로 이동**(2026-07-24 결정, 복사 아님). 취소해도 **이동된 위치에 파일 유지**. `_출력` 중복 EPS는 C(카드 경로 노출) 도입 시 제거 |
| D9 | 성능 = **확정 후 배치 저장** | 무거운 EPS 저장을 확정 뒤로 몰기. (선택) EPS 저장옵션·PDF 포맷·진행표시 |

### D8 보강 — 확정 시 조직폴더 이동 (2026-07-24 결정, 구현 전 정렬 필요)
- **이동 실행자 = 에이전트(서버 PC)**. ⚠️ **MES=Cloudflare Workers는 Z: NAS 직접 접근 불가** → MES는 "이동 지시"(target path)만 기록, 실제 `mv`는 에이전트가 수행(ingest의 역방향 잡).
- **경로**: `Z:\<archive>\<인쇄방식>\<YYYY>\<MM>\<DD>\<order_number>\`. `order_number`=기존 `E{eid}-{YYYYMMDD}-{seq}`(`getNextEntitySeqNumber`, create.ts:71). `인쇄방식`=품목 코드범위(PM-1수성/2솔벤/3UV/4평판/5전사/6태극기/7간판). archive 루트 `DESIGN` vs `DESIGNS` 확정 필요.
- **미해결 서브결정**: ① 혼합 인쇄방식 주문(UV+솔벤 등) 라우팅 = 품목/카드별 분산 vs 대표방식 통합 vs 방식별 하위폴더. ② 날짜 기준(주문일 vs 납기). ③ 이동 순서 = **ingest(대기함 생성) 이후**에만 이동(스캔 유실 방지). ④ 이동 후 intake/카드/manifest 경로 갱신·부분실패 멱등.
- **미구현**: 주문서↔폴더 연동(B 연동) 자체가 아직 설계 단계 → 이동 로직은 그 위에 얹음.

### 3.5 가공자 신원 (내 작업 로그인 = 신원 태깅)
JSX는 HTTPS 불가 → 팔레트에서 **실제 MES 비번 인증은 불가**. 채택 방식:
- **신원 태깅**: 팔레트 **가공자 드롭다운**에서 본인 선택 → **로컬 기본값 저장**(재설정/전환 전까지 유지) → manifest `registered_by` = 선택 유저 **id**(동명이인 대비).
- 트레이 **"내 작업" = MES 로그인 유저 = `registered_by`** 매칭.
- **초기 가공자 roster (4인)**: 인호동 · 김보연 · 정소은 · 김영주.
- ⚠️ **구현 전제**: 이 4인이 **MES 유저(디자이너 역할)로 존재/매핑**돼야 로그인 상관 성립. 계정 생성·매핑은 **구현 단계 선행 작업**(본 문서 범위 밖).
- (실인증이 꼭 필요하면 "에이전트 경유 로그인 릴레이"로 승격 — NAS 왕복, 보류)

## 4. 사용자 흐름

### 4.1 가공 (팔레트 + 반자동 큐)
1. 파일 열고 검수(기존) → **F키로 팔레트 활성**(또는 상주 패널). **가공자 선택**(로컬 기본값)
2. **"디자인 자동 감지"**(선택) → ExtractGroups 시드가 제안 N개를 큐에 채움 / 또는 **선택→"큐에 추가"** 반복
3. 큐 교정(놓친 것 선택 추가·틀린 것 삭제) → 행별 **거래처(자동완성)·마감·수량·배율** 세팅(프리셋)
4. **검토문서 생성** — 큐 N디자인을 **디자인당 아트보드**로 가공(마감·돔보) → **일러에서 Fit All/줌/아트보드 이동으로 확인** → **[일괄 확정]**
5. 확정 시에만: 아트보드별 **EPS 배치 저장** + work.ai + thumb + manifest(건별 폴더) → 에이전트 ingest → 대기함(waiting, `batch_key`·`client_id`·`registered_by`)

> ⚠️ 큐 = **단일 출력 가공**용. impose(판짜기 대상) 디자인은 work.ai만(돔보·마감 없음) **판짜기 경로**로 — 큐에 섞이지 않게 모드 분리.

### 4.2 주문 연동 (2방향)
- **파일선행(주력)**: 대기함 트레이 → "내 작업" → **파일 그룹 선택 → "이 작업으로 주문 생성"** → 주문서 프리필(거래처 상속 + N라인)
- **주문선행(가끔)**: 주문서 거래처 선택 → 대기함 **거래처 자동필터** → 파일 그룹 선택 → 라인 추가
- 동시작업(예: A 2 / B 20 / C 10 = 32건)도 **"내 작업" + 거래처 + 작업(파일) 3중 스코핑**으로 "지금 쓰는 주문에 필요한 몇 개"로 좁혀짐
- ⚠️ 배치 프리필 = 각 라인↔intake **`order_item_id` 매핑 absorb**(`workbench.ts:1268` 경로)로 추적 유지 — bulk absorb(`:1252`)는 order_item_id 없어 배치엔 부적합

### 4.3 오퍼레이터
MES 로그인 → 생산/출력 대기열(카드 상태로 남은 작업) → 카드의 **Z: 경로로 파일 열기** → RIP 수동 삽입 → 출력완료/출고 상태 갱신(/ship)

## 6. 연쇄영향·리스크

- **JSX HTTPS 불가**: 거래처 리스트·가공자 인증 모두 **직접 API 불가** → 에이전트 config 중계(거래처)·신원 태깅(가공자)로 우회. 실인증 아님(신뢰경계=PC, 내부 6인 환경 허용).
- **config 거래처 리스트 재도입**: id+name ~3000행 ≈ 100~150KB. 로컬 파일 자동완성이라 매 타건 네트워크 아님 → 부담 없음. 과거 LIMIT은 쿼리 상향/청크로 해소.
- **ScriptUI 도킹 자체가 PoC 검증 대상**: Startup 도킹은 일러 버전별 quirk → **A1 첫 관문 = "도킹 가능 여부" PoC**. 실패 시 플로팅 팔레트/CEP 승격. **★A0 결과(2026-07-23, 일러 2026/30.3.0): ScriptUI palette 자동실행·표시는 성공(단 `#targetengine` 필수·Startup 폴더=설치 루트)했으나 네이티브 도킹 실패(플로팅·뒤로 감·조작난) → No-go → CEP 승격 실행**(`IllustratorAutomat/designer/poc-a0-cep/`, CEP 12 네이티브 도킹 패널, mes-core 처리 연결·설치·PlayerDebugMode 완료).
- **확정 게이트 흐름 재배치**: manifest="커밋 마커" → 확정 시 기록. 검토문서(다중 아트보드) 상태 관리 주의(복제문서).
- **ExtractGroups 시드 부정확**: 혼합 파일 오·과분할 → **A1a 수동 큐로 폴백**(시드 없이도 동작).
- **일러 대지 한도**: 검토문서 합산 타일이 ~577cm/227in 초과(대형) → 순차 검토 폴백(D4). 출력 per-design은 무관. **★A0 실측 확정(2026-07-23, AI 2026/30.3.0): 단일 문서 max = 577cm(578 FAIL), `documents.add` 경로.** 검토문서 생성기는 작은 기본문서 리사이즈 금지(캔버스 좌표 범위에 먼저 걸려 ~200~400cm로 낮아짐) → 목표크기로 문서 생성 필수.
- **EPS 파일명 충돌**: 다중 디자인 동일 거래처·크기·수량 → 덮어씀 → 디자인 index 접미로 해소.
- **배치 저장 부분실패**: N건 중간 중단 → 디자인별 manifest 커밋 마커로 멱등·재시도.
- **상주 도킹 = Startup 스크립트 설치**: 도킹 팔레트는 Startup Scripts 폴더 로드 필요(F-key 스텁과 설치 모델 다름) — A0에서 검증. **★확정: 자동실행 폴더 = 설치 디렉터리 루트 `Startup Scripts\`(Plug-ins 하위 아님). CEP는 `%APPDATA%\Adobe\CEP\extensions\`(관리자 불요·일러 업데이트 생존).**
- **가공자 roster ↔ MES 계정 매핑**: 4인이 MES 유저로 존재해야 "내 작업" 성립 → 구현 선행 확인.
- **원본 불가침**: 시드 감지는 read-only만, CMYK/아웃라인 변환은 복제문서에서만(§5). 라이브 원본 훼손 방지.
- **브랜치 정합**: 현 `feat/dept-pnl`은 `session/ia-web-sunset` mes-sheet P1a·크래시픽스(`31c88d00`)보다 뒤짐 → 팔레트는 판짜기 무수정(런처만) + 착수 전 정합([[project-ia-web-sunset]]).
- **Startup + NAS 타이밍**: startup `evalFile(Z:)`가 NAS 미마운트 시 로드 실패 → 존재 가드 + 재시도/수동 재로드.
