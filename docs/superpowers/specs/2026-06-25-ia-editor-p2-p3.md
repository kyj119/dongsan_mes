## ① 다중 그룹 일괄 가공 + ZIP — 프론트 위주
- `iaEditor.js`: 그룹 리스트 헤더(~289)에 `전체 가공` 버튼 → `f.groups` 순회하며 각 그룹 settings로 `POST /process` 다중 잡 큐잉(잡 id 배열). 진행 표시(N/M 완료), 완료분 이력/결과 누적.
- **ZIP**: 일괄 완료 후 `ZIP 받기` 버튼 → 각 잡의 EPS/JPG/DXF를 `iaeDownloadBlob` 대신 axios blob으로 받아 **fflate `zipSync`**(cardExpenses.js 패턴)로 묶어 다운로드. 파일명 `{그룹명}_{사이즈}.{kind}`. 워커/에이전트 무변경(기존 process 잡 재사용).

## ② 에이전트 진행 가시성 + 재시도 — 폴링이 곧 heartbeat
- **워커**: `GET /process-queue`·`/render-queue` 핸들러에서 `INSERT OR REPLACE INTO settings(key,value) VALUES('ia_agent_last_seen', datetime('now'))`(settings 키-값 패턴은 기존 라우트 참조). 신규 `GET /api/workbench/agent-status` → `{online:boolean(last_seen<60s), last_seen}`. 신규 `POST /api/workbench/process/:id/retry`(entity 격리, status error|rendering → queued, result_json/error 초기화).
- **에이전트**: 별도 변경 불요(폴링 자체가 heartbeat). 단 폴링 주기 짧게 유지 확인.
- **프론트**: 가공 폴링 UI에 경과시간 표시. `GET /agent-status` 주기 조회 → `에이전트 온라인/N초 전 응답` 배지. error·timeout 시 `재시도` 버튼(`POST /process/:id/retry` → 재폴링).

## ③ 가공 전 실제 렌더 미리보기 (JPG 1장, 경량) — jsx preview 모드
- **jsx (ProcessOrderItem.jsx)**: 신규 `var preview = _p.preview || false;`. 가드(L72) `if (!sourceFile || (!outputEps && !passthroughThumb && !preview))`로 확장. preview면 **가공(마감/돔보/회전/스케일)은 그대로 수행, EPS saveAs만 스킵**, JPG는 `outputJpg`로 export(기존 L781 경로). DXF도 스킵.
- **에이전트**: `params.preview_only` → `iaParamsObj.preview=true`, `epsOutput`은 빈 문자열(또는 미지정), `jpgOutput`만 지정. 결과 R2 업로드 없이 `jpg_base64`만 콜백(status done, result_json={jpg_base64,width_cm,height_cm,preview:true}). 출력 폴더 임시(`process_preview_{id}`).
- **워커**: `POST /process` body에 `preview_only?:boolean` → params. **`GET /process` 목록에서 preview_only 잡 제외**(이력 오염 방지 — params_json LIKE 또는 result preview 플래그).
- **프론트**: 인스펙터에 `미리보기` 버튼 → `POST /process {preview_only:true, ...현재 settings}` → 폴링 → `jpg_base64`를 라이트박스/패널에 표시(마감·돔보·회전·왜곡 실렌더 확인). 가공 전 시행착오 제거.

## ④ 배치 전 실시간 예상치 — 프론트 only
- `iaEditor.js`: 네스팅 패널 입력(수량/규격/모드/크기/간격/여백) change 시 `iaeShelfBinPack` 드라이런(실제 배치 안 함) → 패널 하단에 `예상 효율 %·예상 롤 길이(롤) 또는 판 수(평판)·자투리` 라이브 표시. `대지에 배치` 전에 규격·회전 조합 비교.

## ⑤ 화면 돔보 오버레이 출력 형상 일치 — 프론트 only
- `iaEditor.js`: `iaeCanDrawOverlays` trim 렌더(~1024~1031)의 L자 트림선을 ProcessOrderItem 돔보 규격(꼭짓점 1cm 바깥 **원**, 상단 6cm **방향마크** 1개, 50cm 초과 시 **중간마크**)으로 재현. 시트 trim(~1044~1051)도 동일. 모양·개수·방향 1:1(상하 뒤집힘 방지).

## ⑥ RESIZE 0.1cm 정밀도 + 비율왜곡 강한 경고 — 프론트 only
- `iaEditor.js`: 주문 라인 `w_cm`/`h_cm`·RESIZE pp의 `Math.round(w_mm/10)`(~1523,1547)을 `Math.round(*10)/10`(0.1cm)로 변경(인스펙터 step=0.1 정합). 비율 diff>0.05(~1156) 시 주문/가공 버튼에 `N% 왜곡, 진행?` 확인 모달 게이트, 비율잠금 해제 시 토스트.

## ⑦ 자동배치 좌표 sync 일원화 — 프론트 only
- `iaEditor.js`: `iaeCanNestPlace`에서 객체 생성 직후 `iaeCanSyncSheet` 즉시 호출해 placements 재계산(현재 ~1315 인라인 placements 대신). 회전 x보정(~1319)과 주문 시 bbox 재계산(~1233) 이원화 제거 → 화면↔출력 단일 소스.

## width_cm 보강 (P1 잔여) — 에이전트
- `Program.cs ProcessSingleProcessJobAsync` result(~1604)에 `width_cm`/`height_cm` 채움(targetW>0이면 target, 아니면 EPS BoundingBox 또는 검출). 이력 카드 크기 0 표시 해소.

## API 계약 (R1)
- `GET /api/workbench/agent-status` → `{success,data:{online,last_seen}}`
- `POST /api/workbench/process/:id/retry` → `{success}` (error|rendering→queued)
- `POST /api/workbench/process` body 확장: `{...기존, preview_only?:boolean}`
- `GET /api/workbench/process` 목록: preview_only 잡 제외
