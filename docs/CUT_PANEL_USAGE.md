# 재단 사용법 (MES 가공·재단 패널 — 재단 탭)

> 칼선(재단 파일) 제작 + 이형 네스팅. spec = `docs/superpowers/specs/2026-07-31-cut-file-panel.md`
> **2026-08-04 병합** — 재단 패널은 없어지고 가공 패널의 **「재단」 탭**이 됐습니다.
> 창이 하나라 가공↔재단을 오갈 때 패널을 찾아 열 필요가 없습니다.
> 로직(호스트)은 여전히 `mes-a0-host.jsx` · `mes-cut-host.jsx` **2파일**이라 재단만 되돌릴 수 있습니다.

## 0. 열기

**창(Window) > 확장(Extensions) > MES 가공·재단** → 상단 **[재단]** 탭

- 우상단에 `shell 0.14.0 · host CUT-CEP-0.9.2` 처럼 뜨면 정상입니다(재단 탭에서만 보입니다).
- `ERROR ...` 면 Z: 연결 문제입니다(로직 정본이 `Z:\DESIGNS\IA-등록\_scripts\mes-cut-host.jsx`).
- 설치/갱신 = `Z:\DESIGNS\IA-등록\_scripts\install-a0-panel.ps1` 실행 후 **일러 재시작**.
  - 구 「MES 재단」 확장은 이 스크립트가 **백업 후 지웁니다**(같은 기능이 둘이면 헷갈립니다).

---

## 1. 칼선 만들기

1. 일러에서 **대상 그림을 선택**합니다(전체선택 Ctrl+A 도 됩니다 — 재단선 레이어는 자동 제외).
2. 패널에서 설정:

| 항목 | 설명 |
|---|---|
| **오프셋** | 그림 바깥으로 벌릴 거리(mm). 모서리는 자동으로 둥글어집니다(반지름 = 오프셋) |
| **방식** | `사각` = 선택 영역 기준 / `실루엣` = 그림 외곽을 따라감 |
| **배경** | 실루엣일 때만. `자동` 권장 — 아래 §1.1 |
| **타공** | 체크하면 개수·안쪽 거리(mm)로 지름 6mm 구멍을 둘레에 등간격 배치 |
| **DXF 동시 저장** | CNC 재단용 `.dxf` 를 함께 저장(mm 단위, **칼선만** 담김) |

3. **[칼선 만들기]** 를 누릅니다.
4. 현재 문서의 **`재단선` 레이어**에 마젠타(M100) 0.6pt 실선으로 생깁니다.

### 1.1 배경 설정이 중요한 이유

- 벡터 그림은 배경이 투명이라 `자동`이 알아서 처리합니다.
- **사진·이미지(임베드 래스터)는 배경이 흰색**이라 그대로 두면 **사각형**이 나옵니다.
  `자동` 이 흰 배경이 넓다고 판단하면 제거하고, 결과창에 `배경: 흰 배경 제거 (자동)` 이라고 표시합니다.
- ⚠️ **흰 배경 제거는 흰색 그림도 함께 지웁니다.** 흰 글자·흰 로고가 있으면 `투명 배경` 으로 지정하세요.

### 1.2 구멍(ㅇ·ㅁ·0·8 속)

자동으로 뚫립니다. 단 **지름 2mm 미만 구멍은 무시**합니다 — 칼날이 들어갈 수 없고, 글자 사이 좁은 틈이 오프셋으로 막히며 생기는 노이즈가 대부분입니다.

### 1.3 자주 나오는 안내

- `※ 조각들이 이어졌습니다` — 오프셋이 조각 간격의 절반보다 커서 붙었습니다. **낱개로 떼려면 오프셋을 줄이세요.**
- `선택이 재단선뿐입니다` — 칼선만 선택돼 있습니다. 그림을 선택하세요.

---

## 2. 네스팅 (여러 조각을 시트에 촘촘히)

1. 배치할 **조각들을 선택**합니다. **조각 = 선택된 최상위 아이템 하나**입니다.
   - 그룹 6개를 선택하면 조각 6개로 봅니다.
   - 2개 이상이어야 실행됩니다.
2. `네스팅 — 여러 조각을 시트에 촘촘히` 를 펼치고 설정:

| 항목 | 설명 |
|---|---|
| **시트** | 롤 914/1050/1270/1370/1520mm(폭 고정·길이 가변) 또는 평판 900×1800 / 1200×2400 |
| **간격** | 조각 사이 최소 거리(mm) |
| **회전 허용** | 0/90/180/270 중 유리한 방향을 고릅니다. 방향성 소재면 끄세요 |

3. **[네스팅 실행]**
4. 결과가 **새 문서**로 만들어집니다 — **원본 문서는 그대로**입니다. 저장은 직접 하세요.
5. 결과창에 `롤 길이 93mm · 효율 58.6%` 처럼 사용량이 나옵니다.

### 2.1 지금 되는 것 / 안 되는 것

| | |
|---|---|
| ✅ | 열려 있는 **한 문서 안의** 여러 조각 네스팅 (실제 `.ai` 파일로 검증됨) |
| ✅ | 이형(삼각·원·L·글자) 맞물림 — bbox 패킹 대비 삼각형 기준 **40% 절감** |
| ✅ | 롤(길이 최소화)·평판(여러 장 자동 분할) |
| ❌ | **여러 파일의 조각을 모아서** 네스팅 — 현재는 활성 문서의 선택만 봅니다 |
| ⏳ | 플로터/CNC 실기 투입 — **아직 미검증**입니다(파일 형식은 실물과 같은 구조로 맞춰 뒀습니다) |

> **여러 파일을 함께 배치하려면**: 각 파일에서 복사해 한 문서에 모은 뒤 네스팅하세요.

### 2.2 조각이 많으면 느립니다

조각마다 이미지를 한 번씩 구워야 해서, 수십 개면 수십 초 걸립니다. 진행 상황은 결과창에 `조각 굽는 중... 5/12` 로 표시됩니다.

## 3. 진단 · 잠금

`진단 · 잠금` 을 펼치면:

- **[잠금 상태]** — 지금 누가 일러를 점유 중인지. A0 패널이 작업 중이면 `seen:a0:single` 처럼 보입니다.
- **[잠금]/[해제]** — 수동 점유(보통 쓸 일 없습니다).
- **[강제해제]** — 패널이 죽어 잠금이 남았을 때만. 남의 작업 중에 누르면 충돌합니다.

> 두 패널(A0·재단)이 같은 일러를 동시에 때리지 않도록 **잠금 파일**(`%TEMP%\mes_host_lock.txt`)로 서로를 봅니다. 10분이 지나면 자동 회수되므로 영구 잠김은 없습니다.

## 4. 문제가 생기면

| 증상 | 확인 |
|---|---|
| 우상단이 `ERROR 정본 없음` | Z: 연결. `mes-cut-host.jsx` 가 `Z:\DESIGNS\IA-등록\_scripts\` 에 있어야 합니다 |
| 버튼이 잠겨 있음 | `title` 에 이유가 뜹니다(예: `geometry.js 미로드` → 패널 재설치) |
| 칼선이 사각형으로만 나옴 | 방식이 `사각` 이거나, 사진인데 배경이 `투명 배경` 으로 지정돼 있습니다 |
| 화면이 옛날 버전 | 패널을 **닫았다 다시 여세요**. 그래도 그대로면 `install-a0-panel.ps1` 재실행 후 일러 재시작 |
| 「MES 재단」이 아직 보임 | 구 확장이 남았습니다 — `install-a0-panel.ps1` 을 다시 돌리세요(일러 종료 후) |
| 결과가 이상함 | 결과창 문구를 그대로 알려주세요 — 어떤 배경 판정·해상도를 썼는지 다 적혀 있습니다 |
